1. 背景与目标

背景：

- 现在一个监控任务可以配置多个校验规则， 而不同的规则是针对同一张表的不同字段值进行校验， 现有的逻辑是每个规则都需要扫描两次源表（一次获取阈值， 一次写入脏数据）。在亿级别的数据量的情况下频繁扫表， 会对集群产生不小的压力。

目标：

- 在不改规则逻辑提前下，针对单字段或者简单聚合校验规则进行合并， 比如空值数、空值率、空串数三个规则原本需要扫描3次， 优化为扫描1次。

------

## 2. 范围与优先级

范围：

- 数据源类型：

- SparkThrift、Hive、Doris2.x+

- 合并前提

- 单表、且filter完全相同（仅比较标准化后字符串）
- 规则判断只依赖当前行、不依赖于gropy by、
- 不依赖于窗口函数、不依赖于统计边界值
- 不依赖于多表join、不属于正则模板
- 强弱规则完全相同

-  单字段规则列表：

- 空值数、空值率、空串数、空串率、数值-枚举范围、负值比、零值比、正值比、数值-取值范围、枚举值

-  简单聚合类：

- 表行数、字符串-最大长度、字符串-最小长度、求平均、求和

不做：

- 上述规则以外的规则
- 自定义脏数据存储字段，不包含自定义SQL、多表规则

待定：

- 脏数据合并

- 合并后限制脏数据写入1万条无法实现
- 合并后影响脏数据明细查看和质量报告脏数据下载业务

- 之前单表, 直接走JDBC简单查询较快

- SELECT * FROM dq_monitor_xx LIMIT 1000;

- 合并后：

- SELECT * FROM dq_monitor_xxx WHERE xxx = xxx LIMIT 1000;

​    由于带上过滤条件直接走JDBC可能导致STS内存溢出影响产品稳定性， 那就只能走on yarn 流程。

​    构建SQL -> 构建调度实例提交调度 -> 调度根据集群资源提交到Yarn集群 -> 轮询调度实例状态 

-> 实例运行完成之后 -> 在通过读取HDFS 文件数据 -> 展示查看脏数据明细界面/质量报告的脏数据Excel中

------

## 3. 现状分析

当前实现：

- 在保存监控规则的时候，生成对应的阈值查询SQL以及脏数据查询SQL
- 在提交到调度的时候， 如果设置了多个规则包，首先根据强弱规则进行分包，构建不同的SQL任务
- 针对每个规则包里面的规则执行concatSql方法将阈值SQL和脏数据SQL拼接到一个SQL文件里面， 每个规则使用Union进行拼接
- 将SQL构建成调度任务， 并构建工作流任务提交到调度

存在问题：

- 在规则包分包的时候， 没有按照可合并规则进行分包
- 在ConcatSQL的时候， 每个监控规则单独输出，没有进行规则合并

涉及模块：

- 监控任务的保存
- 监控任务的手动运行
- 任务实例的手动运行
- 任务详情的脏数据查看

------

## 4. 核心设计

核心对象：

- 监控规则

核心流程：

1. 在监控规则保存的时候逻辑保持不变（生成对应的阈值查询SQL以及脏数据查询SQL），在规则不能合并的时候，走之前的默认逻辑
2. 在多个规则包的情况下， 首先按照规则强弱进行分包， 在上述的前提下，在优先按照可合并规则进行划分
3. 在ConcatSQL的时候，提前判断可合并的规则并进行合并，原始的逻辑保存不变

合并流程图：

```plain
规则包
  ↓
按强弱规则分包
  ↓
识别可合并规则
  ↓
构建 MergeKey
  ↓
生成 MergeGroup
  ↓
MergeGroup 生成合并 SQL
  ↓
不可合并规则走原 union SQL
  ↓
拼接最终 SQL 文件
  ↓
提交调度执行
```

方案说明：

- 本次采用执行期合并， 保存期不动的方式

- 规则保存时，仍按现有逻辑生成并保存单条规则的 `customizeSql/selectDataSql`
- 任务执行时，在 `concatSql(...)` 阶段识别哪些规则合并
- 非合并规则走原有的逐条union 逻辑。

- 合并原则

只有满足以下条件的规则，才能进行合并, 任意维度不同，继续走之前的逻辑

- 单表、且filter完全相同（仅比较标准化后字符串）
- 规则判断只依赖当前行、不依赖于group by、
- 不依赖于窗口函数、不依赖于统计边界值
- 不依赖于多表join、不属于正则模板
- 强弱规则完全相同

- 需要考虑校验类型为占比的场景

- 函数本身需要比率

- 空值率、空串率、负值比、零值比、正值比等

- 校验类型为：占比

- expansion兼容性

  本次合并不能只关注val， 还需要保证expansion与原有结果一致， 因为在质量报告中使用

- 默认固定值，通常为 '0'
- 占比规则， 命中数/总数
- 部分规则有额外含义， 需要每个规则具体看下

- 开启抽样后的兼容性

  	抽样规则理论上需要同样对合并规则生效

 * 将监控规则划分为「待合并分组」与「不可合并」两类。
 * <p>
 * 1. functionId 属于指定集合且 columnNameStr（{@link MonitorRule#getColumnName()}）、filter 均相同的规则归为一组，加入 waitingMargeList；其余加入 unableMargeList。

protected MonitorRuleMergePartition classifyMonitorRulesForMerge(List<MonitorRule> monitorRuleList) {
    List<List<MonitorRule>> waitingMargeList = Lists.newArrayList();
    List<MonitorRule> unableMargeList = Lists.newArrayList();
    if (CollectionUtils.isEmpty(monitorRuleList)) {
        return new MonitorRuleMergePartition(waitingMargeList, unableMargeList);
    }
    Map<String, List<MonitorRule>> mergeKeyToGroup = new LinkedHashMap<>();
    for (MonitorRule rule : monitorRuleList) {
        Long functionId = rule.getFunctionId();
        if (functionId != null && MERGEABLE_BY_COLUMN_FILTER_FUNCTION_IDS.contains(functionId)) {
            String mergeKey = buildColumnFilterMergeKey(rule.getColumnName(), rule.getFilter());
            mergeKeyToGroup.computeIfAbsent(mergeKey, k -> Lists.newArrayList()).add(rule);
        } else {
            unableMargeList.add(rule);
        }
    }
    waitingMargeList.addAll(mergeKeyToGroup.values());

        List<MonitorRule> group = groupIt.next();
        if (group.size() == 1) {
            groupIt.remove();
            unableMargeList.add(group.get(0));
        }
    }
    return new MonitorRuleMergePartition(waitingMargeList, unableMargeList);
}

/**
     * {@link #buildPackageSerialNumberRelationRules} 的优化版本：强弱规则经 {@link #classifyMonitorRulesForMerge(List)} 后，
     * 强、弱两侧各自 waiting 优先、unable 补充并均衡分包；<b>强规则与弱规则不得混在同一包</b>（按包下标区间隔离）。
     * 特殊包数（1、2、等于规则总数）单独处理。入参、返回值与原方法一致。
     */
    protected Multimap<Long, MonitorRule> buildPackageSerialNumberRelationRulesV1(Long tenantId, Long projectId, int packageCount, Long monitorId) {
        Multimap<Long, MonitorRule> multimap = ArrayListMultimap.create();
        MonitorRuleDao monitorRuleDao = SpringUtil.getBean(MonitorRuleDao.class);
        List<MonitorRule> monitorRules = monitorRuleDao.listByMonitorId(monitorId, tenantId, projectId);

        List<MonitorRule> monitorStrengthRules = monitorRules.stream().filter(rule -> rule.getRuleStrength() == RuleStrength.STRENGTH.getType()).collect(Collectors.toList());
        List<MonitorRule> monitorWeakRules = monitorRules.stream().filter(rule -> rule.getRuleStrength() == RuleStrength.WEAK.getType()).collect(Collectors.toList());

        final long leastOnePackageCount = 1L;
        int totalRuleCount = monitorRules.size();
        if (packageCount > totalRuleCount) {
            throw new DqDefineException("规则包个数需要小于等于对应的规则配置总数");
        }
        if (packageCount == 1) {
            List<MonitorRule> allRules = Lists.newArrayList(monitorWeakRules);
            allRules.addAll(monitorStrengthRules);
            multimap.putAll(leastOnePackageCount, allRules);
            return multimap;
        }
        if (packageCount == 2) {
            multimap.putAll(1L, monitorStrengthRules);
            multimap.putAll(2L, monitorWeakRules);
            return multimap;
        }
        if (packageCount == totalRuleCount) {
            for (int i = 0; i < monitorRules.size(); i++) {
                multimap.put((long) (i + 1), monitorRules.get(i));
            }
            return multimap;
        }

        MonitorRuleMergePartition strengthPartition = classifyMonitorRulesForMerge(monitorStrengthRules);
        MonitorRuleMergePartition weakPartition = classifyMonitorRulesForMerge(monitorWeakRules);

        int strengthRuleCount = monitorStrengthRules.size();
        int weakRuleCount = monitorWeakRules.size();
        int[] strengthWeakSlots = resolveStrengthWeakPackageSlotCounts(packageCount, strengthRuleCount, weakRuleCount);
        int strengthSlotCount = strengthWeakSlots[0];
        int weakSlotStart = strengthWeakSlots[1];

        List<List<MonitorRule>> bins = Lists.newArrayListWithCapacity(packageCount);
        int[] loads = new int[packageCount];
        for (int i = 0; i < packageCount; i++) {
            bins.add(Lists.newArrayList());
        }

        distributeMergeFirstBalancedInSlots(bins, loads, strengthPartition.getWaitingMargeList(), strengthPartition.getUnableMargeList(), 0, strengthSlotCount);
        distributeMergeFirstBalancedInSlots(bins, loads, weakPartition.getWaitingMargeList(), weakPartition.getUnableMargeList(), weakSlotStart, packageCount);

        for (int i = 0; i < packageCount; i++) {
            multimap.putAll((long) (i + 1), bins.get(i));
        }
        return multimap;
    }

    /**
     * 按规则条数为强、弱两侧划分可用包个数：仅强或仅弱时占满全部包；两侧均有则至少各 1 个包，其余按条数比例四舍五入并夹在 [1, P-1]。
     */
    private static int[] resolveStrengthWeakPackageSlotCounts(int packageCount, int strengthRuleCount, int weakRuleCount) {
        if (strengthRuleCount <= 0) {
            return new int[]{0, packageCount};
        }
        if (weakRuleCount <= 0) {
            return new int[]{packageCount, 0};
        }
        int strengthSlots = (int) Math.round(packageCount * (double) strengthRuleCount / (strengthRuleCount + weakRuleCount));
        strengthSlots = Math.max(1, Math.min(packageCount - 1, strengthSlots));
        int weakSlots = packageCount - strengthSlots;
        return new int[]{strengthSlots, weakSlots};
    }

    /**
     * 在给定包下标区间内：先将 waiting 分组整组放入，再逐条放入 unable；每步仅在区间内选当前规则数最少的包，使该区尽量均衡。
     */
    private void distributeMergeFirstBalancedInSlots(List<List<MonitorRule>> bins,
                                                     int[] loads,
                                                     List<List<MonitorRule>> waitingGroups,
                                                     List<MonitorRule> unableRules,
                                                     int slotStartInclusive,
                                                     int slotEndExclusive) {
        if (slotStartInclusive >= slotEndExclusive) {
            return;
        }
        for (List<MonitorRule> group : waitingGroups) {
            if (CollectionUtils.isEmpty(group)) {
                continue;
            }
            int idx = indexOfMinLoadInRange(loads, slotStartInclusive, slotEndExclusive);
            bins.get(idx).addAll(group);
            loads[idx] += group.size();
        }
        for (MonitorRule rule : unableRules) {
            int idx = indexOfMinLoadInRange(loads, slotStartInclusive, slotEndExclusive);
            bins.get(idx).add(rule);
            loads[idx]++;
        }
    }

    /**
     * 在 [from, toExclusive) 下标范围内选取当前负载（规则条数）最小的包下标。
     */
    private static int indexOfMinLoadInRange(int[] loads, int from, int toExclusive) {
        int best = from;
        for (int i = from + 1; i < toExclusive; i++) {
            if (loads[i] < loads[best]) {
                best = i;
            }
        }
        return best;
    }
