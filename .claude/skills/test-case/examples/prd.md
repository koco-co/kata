## 确认内容

逐条书写，每条末尾标注来源：【需求源】/【知识库】/【源码】/【用户确认】。六个维度没有的写「无」，不许留空节。

### 业务条件与前置

- 新建「单表校验规则」时，统计函数新增可选项「枚举值个数」，统计所选字段去重后的枚举值个数。【需求源】
- 已存在的单表校验规则可编辑为「枚举值个数」，历史告警记录不受影响。【用户确认】
- 规则运行依赖已关联的数据源与表，前置是项目内存在可用数据源。【知识库】

### 边界值

- 枚举值个数为 0（表为空）时按 0 参与阈值比较，不报错。【用户确认】
- 阈值允许填 0 与正整数；负数与超过 2^31-1 的整数禁止提交。【需求源】

### 枚举全集

- 统计函数全集：行数、空值个数、重复值个数、枚举值个数（本次新增）。【需求源】
- 比较符全集：大于、大于等于、小于、小于等于、等于。【需求源】

### 异常流

- 所选字段在运行时不存在（被删列）：规则运行失败，任务状态为「失败」，告警信息写明缺失字段名。【知识库】
- 数据源连接失败：规则运行失败，不重试，记录失败原因。【用户确认】

### 权限与角色

- 项目成员可创建与编辑规则；只读成员只能查看，「新建监控规则」按钮不可见。【知识库】

### 数据依赖

- 验证表：`${DataSourceA}` 下的 `user_profile`（含 id BIGINT、city STRING、status INT）。【用户确认】

## 设计原则

按默认：正常流 / 异常流 / 边界全覆盖；枚举值逐项覆盖；P0 占比约 1/4 ~ 1/3。
