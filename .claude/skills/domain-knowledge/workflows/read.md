# 查询项目知识

## Steps

1. 收窄查询
   - 模块事实使用 `--module`，报错或术语使用 `--keyword`，已知条目类型时再加 `--type`。
   - 默认只读取 `verified`；只有复核历史或冲突时才显式指定其他状态或 `--status all`。
   - 完成条件：查询限定到一个项目，并使用完成任务所需的最小过滤条件。

2. 执行查询

   ```bash
   kata knowledge read --project <项目> \
     [--module <模块>] [--keyword <关键词>] [--type <类型>] \
     [--status <状态|all>] [--json]
   ```

   - 完成条件：命令成功，输出中的每条结果都带有状态；需要机器消费时使用 `--json`。

3. 使用结果
   - `verified` 可作为当前事实。
   - `observed` 只作为待复核线索。
   - `conflicting` 保留双方证据，先裁决再用于业务结论。
   - `deprecated` 只用于追溯历史。
   - 完成条件：回复保留状态差异；无命中时返回“知识库无匹配”，不补写猜测。

## Delivery

返回命中的最小相关条目、状态和来源。项目概览只在与当前问题相关时引用。
