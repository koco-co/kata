# 知识规则

查询或更新项目业务知识时，按本文执行。

项目知识写入 `workspace/{project}/_shared/knowledge/**`，项目规则写入 `workspace/{project}/_shared/rules/**`，后者保存该项目的编写和格式约束。业务事实和实现说明须分仓存放；仅在用户明确要求时，才能把实现上下文记为业务知识。

置信度低的更新，写入前须先和用户确认。除非用户明确指定了目标项目，否则不得跨项目写入。条目尽量简洁、有来源支撑，清楚标注其所属的模块、术语、规则、踩坑或工作流。

查询时，报告命中的知识条目及其 SourceRef ID。无可靠条目命中时，直接说明知识库中没有已确认匹配，不得凭空编造。
