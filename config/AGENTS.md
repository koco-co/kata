# 环境配置约定

- 根 `.env` 只保存仓库级集成配置；DataAssets 平台信息存放在忽略的 `config/env/<env>.yaml`。
- `config/env/` 必须为 `0700`，环境文件必须为 `0600`；目录和文件都不得是软链接或被 Git 跟踪。
- Cookie、密码、令牌、连接串和会话文件都按秘密处理。示例文件只能使用不可用的占位值。
- 平台会携带 Cookie 时默认要求 HTTPS。确需 HTTP 的隔离环境必须显式标明，并由 `doctor` 给出警告。
- 写配置使用同目录临时文件、独占创建、`0600` 权限和原子替换；任何输出都不得包含秘密原文。
- `kata env run` 默认只向子进程传递基础运行变量和该环境所需变量。其他变量必须按名称显式继承，禁止继承整个父进程环境。
- 网络请求必须有超时、取消和有限响应体；错误只返回稳定错误码、目标路径和脱敏说明。
- 环境文件中的 `allow_write` 表示运行意图，不代替数据库、平台或命令层的权限控制。
