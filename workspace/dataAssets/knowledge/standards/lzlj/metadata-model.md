# 泸州老窖(lzlj) 元模型与内置属性用例编写规范

## 0. 适用范围

覆盖 13180、13553、13923、14050 中的 L4/L5 和字段属性能力。

## 1. 菜单与 tags 基线

```text
元数据 → 元模型管理
元数据 → 元数据管理
元数据 → 数据地图（表详情/字段详情消费入口）
```

- 定义或编辑属性：`[元数据, 元模型管理]`。
- 编辑具体表/字段业务属性：`[元数据, 元数据管理]`。
- 核对详情、列表、预览展示：`[元数据, 数据地图]`。

跨页面同步若是一个业务目标，可在步骤中访问消费入口，但 tags 仍标记核心配置或断言页面；不同页面有独立失败含义时拆成用例。

## 2. 自定义属性

- 属性类型：文本框、枚举值、树形目录。
- 文本字段类型：string、bigint；BIGINT 场景分别验证正整数、负数、非数字和超范围值。
- 编辑时属性名和属性类型不可改；中文名、枚举值/树值、必填状态按页面能力修改。
- 删除自定义属性后，列表列和业务值按需求清理；不得把内置属性删除行为混入同一用例。

## 3. 内置属性白名单

- L1～L3：允许编辑白名单内置属性的中文名和必填；英文名、类型不可编辑；删除入口禁用。
- L4：通用业务内置属性只读，无编辑入口；`tb_name_cn`、`manager` 等受保护字段不得写成可编辑。
- L5：允许编辑白名单内置属性的中文名和必填；删除入口禁用。
- 字段 `security_Level`、`privacy_Level`：中文名和必填可编辑，删除入口禁用。
- 后端可能存在删除接口不等于 UI 允许删除；功能用例以可见页面约束为准，不创建纯接口删除用例。

## 4. 全链路同步断言

每次内置属性配置变更只断言该属性实际适用的入口：

- 配置列表：中文名、必填、顺序持久化。
- 新增/编辑表单：标签和必填校验更新。
- 列表/详情：列名和展示顺序更新且不重复。
- 导入模板/导出文件：表头中文名、顺序和必填说明与配置一致。

点击取消时不落库；刷新、重新登录或跨页面后仍展示上次已保存配置。

## 5. L5 字段导入

- 使用 L4/L5 导入弹窗，维度选择 L5。
- 逐项覆盖：必填列、字段定位键、关联标准、安全等级、隐私等级、可落标/已落标、自定义属性格式。
- 一个反向用例只制造一种主错误并核对错误文件对应行；组合错误仅用于验证同一行多错误以中文分号分隔。
