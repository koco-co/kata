# 泸州老窖(lzlj) 数据地图与元数据导入导出用例编写规范

## 0. 适用范围

覆盖需求 13179、13180 中的资产消费入口，以及 13548、13551、13552、13925。

## 1. 菜单与 tags 基线

```text
元数据 → 数据地图
元数据 → 元数据管理
```

- 目录管理（表列表操作入口）：列表查询、目录筛选、状态、发布/下线、置顶/排序/翻页/行拖拽/列拖拽、批量删除、L4/L5 导入导出：`[元数据, 数据目录, 目录管理]`。
- 数据地图（表详情/搜索入口）：搜索与目录树浏览、批量指定目录、表详情与字段列表、数据预览、目录绑定：`[元数据, 数据地图]`。
- 管理的表、表元数据/字段元数据编辑与批量编辑：`[元数据, 元数据管理]`。
- 「资产盘点」是独立统计模块，本需求的 L4/L5 用例不得继续标记为 `[资产盘点]`。

## 2. L4/L5 导入契约

弹窗标题「导入数据」，仅接受 `.xlsx`：

| 配置项 | 规则 |
| --- | --- |
| 导入数据维度 | L4、L5，多选；为空提示「请选择导入数据维度」 |
| 导入数据源类型 | 单选；为空提示「请选择数据源类型」 |
| 上传文件 | 必填；为空提示「文件不可为空！」 |
| 下载模版 | 选择维度和数据源类型后可用 |

注意信息必须覆盖：枚举值已维护、树形值使用 `xx/xxx/xxxx`、已发布资产不更新业务属性、L4 可通过上级目录编码关联目录。

- 错误弹窗：标题「导入失败」，正文「导入表格中存在错误数据，请检查后重新导入。」，按钮「导出错误文件」。
- 错误文件下载提示：「下载成功」或「下载失败」。
- 全部成功提示：「<文件名>文件导入成功」。
- 导入只更新已同步 L4/L5 的业务属性，不创建真实表或字段。

## 3. L4/L5 导出契约

- 弹窗标题「导出数据」。
- 导出维度：L4 数据表、L5 字段，多选；为空提示「请选择导出维度」。
- 导出数据源类型必填；为空提示「请选择数据源类型」。
- 请求携带当前列表筛选条件；导出文件必须逐条属于筛选结果，不得把“页面当前页”误写成导出范围。
- 799/800/801 用于核对分批边界；10000 行场景记录耗时并与 180 秒需求目标比较，但不能把某次环境耗时写成实现硬门槛。
- 异步任务分别核对完成、失败状态和文件可打开性；不得用 Redis key、线程池内部状态作为 UI 功能用例步骤。

## 4. 列表、级联与拖拽

- 每页条数：10、20、50、100，最大 100。
- 列表包含「是否绑定目录」。
- 硬级联顺序：数据源类型 → 数据源 → Catalog → 数据库；清空上级立即清空全部下级已选值。
- 负责人、标签、公司、部门、创建人、更新人等软级联没有已验证后端契约时，只验证当前可见选项和组合查询结果，不臆造级联关系。
- 行拖拽仅在 L3 资产目录上下文且 `UserA` 为管理员时可用；列拖拽可单独验证。

## 5. 数据表状态与批量删除

- 草稿、已下线表可删除；全选已发布表时删除入口禁用。
- 混选已发布与可删除表时，已发布表被静默剔除，只删除可删除表，不出现“全部阻断”提示。
- 删除方式 `META` 只删元数据；`ORIGIN` 删除真实源表。批量删除真实源表时输入表数量必须与待删数量一致。
- 部分失败当前仅写日志且接口整体成功，不向 UI 返回逐对象失败明细；用例应把它记录为已知边界，不能期待“逐对象成功失败结果”。

## 6. 权限账号

- `UserA`：执行查询、导入、导出、发布、下线、删除和拖拽主流程。
- `UserB` 缺少 `METADATA_DMAP_IMPORT_EXPORT`：数据地图「导入」「导出」按钮禁用。
- 其他权限用例必须在前置条件明确 UserB 缺少的权限点，并断言一个确定的 UI 状态。
