# 泸州老窖(lzlj) 数据标准与码表用例编写规范

## 0. 适用范围

覆盖 13182、13183、13184、13185、14050 中的数据标准能力，以及 14280。

## 1. 菜单与 tags 基线

环境已确认：

```text
数据标准 → 标准管理 → 标准定义
数据标准 → 标准管理 → 标准属性管理
数据标准 → 标准管理 → 标准映射
数据标准 → 标准基础 → 词根管理
数据标准 → 标准基础 → 码表管理
数据标准 → 标准基础 → 行业模版
数据标准 → 标准基础 → 数据库拾取
```

用例 tags 使用实际页面，不把「标准目录」作为虚构菜单层级。

## 2. 标准目录与标准定义

- 标准左树复用数据目录 L1～L3；新增标准只能选择已发布 L3 目录。
- 数据目录改名、移动、下线或删除后，标准树同步当前有效状态；已关联标准的目录关系按需求清理。
- 标准列表和表单接入责任人、责任公司/部门、自定义属性、列表列配置、搜索配置、行列拖拽与置顶。
- 标准导出支持「全部」和同层级目录范围；选择一级目录全选时实际导出其下 L3 标准。
- 标准导入反向场景使用错误文件定位，不用历史执行结果作为预期。

## 3. 标准属性

- 属性名、中文名、类型、枚举/文本/树形内容、是否必填按属性表单规范验证。
- 既有标准属性保留【编辑】按钮，但按钮置灰且不可点击；属性字段类型只在新增时选择，用例不得通过编辑切换字段类型或修改枚举/文本配置。
- 标准表单中的 BIGINT 支持正、负整数，STRING 支持文本；两种文本类型分别新增属性并贯穿保存与回显，不把负数写成非法值。
- 枚举空值/重复值、树目录重复和必填分别造数。
- 新增枚举属性后的选项生效范围必须通过标准表单选择项和标准详情中的实际值核对，不只看属性配置列表。

## 4. 码表手工模式

- 新建默认「手工添加」。
- 代码值、代码名称必填；说明、上级代码、状态可选。
- 状态枚举：有效、无效；上级代码和字符型导入值覆盖 255 字符边界。
- 手工导入按代码精确匹配更新；空编码新增；无法匹配或字段非法时阻断并生成错误文件，不静默去重。
- 手工码表内容变化生成版本，支持任意两个版本比对。

## 5. 引用数据表模式

- 数据源类型：Hive2.x、SparkThrift2.x。
- 必填五项：数据源、数据库、数据表、代码值字段、代码名称字段。
- 可选三项：说明字段、上级代码字段、状态字段。
- 级联：切换数据源清空数据库/表/字段；切换数据库清空表/字段；切换表清空字段映射；取消编辑不保存清理结果。
- 详情实时读取源表，最多展示前 1000 条；源不可用、字段不存在、必填映射值为空或代码值重复时明确报错，不降级到旧快照。
- 引用模式不能通过手工导入覆盖源数据。
- 源表数据变化不生成码表版本；只有手工码表内容变化生成版本。
