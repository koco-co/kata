# 泸州老窖(lzlj) 数据权限用例编写规范

## 0. 适用范围

覆盖需求 16178；账号只使用 `UserA`、`UserB`。

## 1. 菜单与 tags 基线

```text
数据安全 → 数据权限管理 → 数据权限分配
数据安全 → 数据权限管理 → 我的权限查看
```

```yaml
tags: [数据安全, 数据权限管理, 数据权限分配]
tags: [数据安全, 数据权限管理, 我的权限查看]
```

## 2. 账号约定

- `UserA`：创建、编辑、禁用、删除或回收权限策略。
- `UserB`：策略生效对象和权限消费账号。每条用例前置条件必须写清 UserB 是否被选为用户、是否属于目标用户组、授权哪些列、行条件和值、有效期。
- 不再使用“管理员、数开、访客”等未定义角色名。

## 3. 策略表单

| 区域 | 规则 |
| --- | --- |
| 权限范围选择 | 数据源 → 数据库 → 数据表，切换上级清空下级 |
| 权限配置 | 表级权限、有效期、是否开启列级权限 |
| 列级权限 | 不配置时默认全部列；配置时只授权选中列 |
| 权限生效用户 | 用户组与用户互斥，至少选择一种；用户支持「全部」 |

## 4. 行级权限

- 操作符全集仅：`=`、`!=`、`in`、`not in`、`is null`。
- `is null` 时值输入框禁用；其他操作符值必填。
- 同一表最多配置 5 行，第 6 行前端阻断，提示「行级权限最大配置5行」。
- 条件内连接为且/或；多条独立策略的外层结果按或汇总。
- 0 条行条件表示该表不做行过滤，但仍受表级和列级权限约束；不能写成“按产品规则保存或不保存”。

## 5. 消费与生命周期

- 行权限作用于数据预览、详情查询和接口查询结果。
- 当前数据导出不应用行权限，功能用例不得期待导出与预览行数一致；可在不覆盖清单记录该实现边界。
- 列权限与行权限组合时，UserB 只能看到授权列中满足行条件的数据。
- 编辑、禁用、删除、回收、到期和移除 UserB 后，预览/详情结果必须反映最新有效策略。
- 越权验证在 UI 可执行入口完成；纯接口鉴权脚本不进入本功能用例集。
