# 泸州老窖(lzlj) 平台管理用例编写规范

## 0. 适用环境与来源

- 环境：http://shuzhan63-dev-lzlj.k8s.dtstack.cn
- 覆盖需求：13176、13181
- 页面与权限以当前定制源码为准；真实账号统一抽象为 `UserA`、`UserB`。

## 1. 菜单路径基线

```text

```

用例 tags 只写实际断言所在页面：

```yaml

```

## 2. 页面契约

### 【编码管理】

- 页面权限：`PLATFORMMGR_CODEMGR_VIEW`。
- 重置权限：`PLATFORMMGR_CODEMGR_RESET`。
- 编码对象：L1、L2、L3、L4、L5、数据标准，各对象独立累计当前值。
- 重置前必须执行可重置校验；存在未删除业务数据时阻断，不得以删除页面记录等价于物理清理。
- 删除或重置后不复用已发放编码；溢出行为以实际当前值递增结果验证，不臆造固定宽度回卷。

### 【目录操作审计】

- 页面权限：`PLATFORMMGR_OPERATION_AUDIT`。
- 记录至少核对：层级、操作对象、编码、操作类别、备注、操作人、操作时间。
- 发布、下线、删除由目录页触发；审计查询在本页面单独断言，不把两个页面塞入一个 tags 层级。
- 批量操作需要逐对象核对审计记录，不只核对总数。

## 3. 前置条件模板

```text
1) 使用 UserA，已授予本用例所需的平台管理页面和操作权限。
2) 已准备唯一命名的 L1～L5 或数据标准数据，不复用其他用例的编码对象。
3) 涉及重置时明确对象是否仍存在未删除业务数据。
```
