# 泸州老窖(lzlj) 数据分级分类用例编写规范

## 0. 适用范围

覆盖需求 13186、13187、13188。

## 1. 菜单与 tags 基线

```text
数据安全 → 数据分级分类 → 级别管理
数据安全 → 数据分级分类 → 自动分级
数据安全 → 数据分级分类 → 分级数据
元数据 → 数据地图（表级和字段级消费结果）
```

表详情/字段详情断言使用 `[元数据, 数据地图]`，不能继续标记为 `[数据安全, 自动分级]`。

## 2. 级别管理

- 同页分别维护安全级别和隐私级别。
- 覆盖新增、重名校验、编辑、无引用删除、存在字段或规则引用时删除阻断、置顶/取消置顶和同分区拖拽。
- 安全级别与隐私级别是两套独立目录；用例必须写明当前 `rankType`，不使用笼统“级别”。
- 新增/编辑级别时必须选择「开放用户等级」；开放用户等级来自用户中心账号等级，是账号权限等级，不是数据资产编码管理或数据级别名称中的 L1～L5。

## 3. 自动分级与分级数据

- 规则至少选择安全分级或隐私分级之一；两个等级字段独立展示和筛选。
- 规则新增/编辑、详情、启停及命中结果按实际等级类型核对。
- 分级数据页支持安全/隐私目录切换、筛选和手动修正；手动分级只展示当前等级目录下可选值。

## 4. 表级汇总

- 13188 的用例执行入口是 `数据安全 → 数据分级分类 → 分级数据` 的「表」检索类型；`元数据 → 数据地图` 表详情仅作为消费结果断言，不作为 13188 主用例入口。
- 字段级分别计算安全等级和隐私等级。
- 表级安全/隐私等级各自取字段中的最高等级，从严汇总。
- 表详情与字段列表展示等级标签；关联标准列和跳转属于数据地图页面。
- 自动结果与手工修正冲突时按需求定义的优先级验证，不把两种来源简单相加。
- 修改字段等级后必须重新进入表详情核对表级汇总，不能只验证页面缓存展示。

## 5. 用户中心账号等级与开放用户等级

- 用户中心 → 账号 → 等级中的 L1～L5 是账号权限等级；与编码管理 L1～L5、数据级别名称不是同一概念，用例中不得混用。
- 抽象账号：`UserA(L5)` 管理员主流程账号；`UserB(L4)` 权限验证账号；`UserC(L1)` 更低等级验证账号。
- 开放用户等级 = L5 时，默认只有 L5 账号可见绑定字段；L4 及以下账号默认不可见，申请审批通过后可见。
- 数据预览是后端字段级可见性断言：未达开放等级的字段值返回「无权限」，前端展示锁图标与「无权限」。
- 表详情/字段列表只断言字段已绑定级别及等级标签展示，不承担字段隐藏断言。
