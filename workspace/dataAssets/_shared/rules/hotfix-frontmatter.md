# Hotfix 用例 Frontmatter 偏好

## keywords 字段

Hotfix 用例的 frontmatter 中**必须**包含 `keywords` 字段，用于快速分类检索。

格式: `"【1】发现的大版本 | 【2】模块 | 【3】数据源类型 | 【4】集群 | 【5】真实解决的最低版本 | 【6】问题原因"`

各字段说明:

| 位置 | 含义               | 示例值                             | 备注                        |
| ---- | ------------------ | ---------------------------------- | --------------------------- |
| 1    | 发现的大版本       | `6.3`                              | 首次发现该 Bug 的产品大版本 |
| 2    | 模块               | `数据模型`、`数据质量`、`元数据`   | 所属功能模块                |
| 3    | 数据源类型         | `SparkThrift`、`MySQL`、`Hive`、`Doris` | 若与数据源无关则留空；证据明确 SparkThrift 时不得写 Spark 或留空 |
| 4    | 集群               | `standalone`、`HA`                 | 若与集群无关则留空          |
| 5    | 真实解决的最低版本 | `6.3`                              | 归一化到最低修复大版本，不得写 `v6.3.41_ltqc`、`6.3.41`、客户缩写、修复分支名或构建号 |
| 6    | 问题原因           | `增量sql中完整性校验json格式校验sql模板未考虑到分区` | 证据中的具体问题原因或修复点摘要，不得写「代码缺陷」「需求变更」「配置错误」等分类词 |

示例:

```yaml
---
suite_name: "Hotfix 用例 - xxx"
keywords: "6.3 | 数据质量 | SparkThrift | | 6.3 | 增量sql中完整性校验json格式校验sql模板未考虑到分区"
tags:
  - hotfix
---
```

留空字段保留分隔符 `|`，确保位置对齐。
