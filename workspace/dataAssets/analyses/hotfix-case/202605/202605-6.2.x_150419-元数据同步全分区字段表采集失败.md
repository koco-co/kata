# 【150419】验证Spark 表所有字段均为分区字段时元数据同步成功，不再误报表不存在

## 前置条件

```
1. 已部署包含 datasourcex 修复分支 hotfix_6.2.x_150419 的包，并更新 agent 中使用的 datasourcex 插件。
2. 已在【数据资产 > 数据源管理】引入 SparkThrift / Spark 数据源，且数据源连接测试成功。
3. 数据源连接的默认数据库为本次 Hotfix 测试库，后续 SQL 均在该数据库下执行。
4. 当前登录账号有【元数据管理 > 元数据同步】新增任务、立即同步、查看实例日志、查看数据地图表详情权限。

-- 1) 主缺陷复现表：所有字段均为分区字段
-- 执行入口：Hive CLI / HMS 管理入口 / 能直接写入 Hive Metastore 的建表入口。
-- 不要在 Spark SQL / SparkThrift 临时查询中执行本段建表 DDL；Spark 会返回 ALL_PARTITION_COLUMNS_NOT_ALLOWED。
-- 该表必须保持普通字段为空、分区字段为 biz_date、region，不能添加 id/name 等普通字段。
DROP TABLE IF EXISTS hotfix_150419_all_partition_cols;

CREATE TABLE IF NOT EXISTS hotfix_150419_all_partition_cols
COMMENT 'hotfix 150419：全字段均为分区字段的 Spark 表'
PARTITIONED BY (
  biz_date STRING COMMENT '业务日期分区字段',
  region   STRING COMMENT '区域分区字段'
)
STORED AS PARQUET;

ALTER TABLE hotfix_150419_all_partition_cols
  ADD IF NOT EXISTS PARTITION (biz_date='2026-05-19', region='east');
ALTER TABLE hotfix_150419_all_partition_cols
  ADD IF NOT EXISTS PARTITION (biz_date='2026-05-20', region='west');

-- 2) Spark SQL / SparkThrift 临时查询入口只执行以下只读检查，确认主缺陷复现表对 Spark 数据源可见：
SHOW TABLES LIKE 'hotfix_150419_all_partition_cols';
DESCRIBE hotfix_150419_all_partition_cols;

-- 3) SparkThrift / Spark SQL 相邻回归测试表
DROP TABLE IF EXISTS hotfix_150419_mixed_partition_cols;
DROP TABLE IF EXISTS hotfix_150419_no_partition_cols;

-- 4) SparkThrift / Spark SQL 相邻回归表：普通字段 + 分区字段
CREATE TABLE IF NOT EXISTS hotfix_150419_mixed_partition_cols (
  id       BIGINT COMMENT '主键',
  name     STRING COMMENT '名称',
  amount   DECIMAL(18,2) COMMENT '金额'
)
COMMENT 'hotfix 150419：普通字段加分区字段的 Spark 表'
PARTITIONED BY (
  biz_date STRING COMMENT '业务日期分区字段'
)
STORED AS PARQUET;

INSERT OVERWRITE TABLE hotfix_150419_mixed_partition_cols PARTITION (biz_date='2026-05-19')
SELECT 1 AS id, 'alpha' AS name, CAST(10.50 AS DECIMAL(18,2)) AS amount
UNION ALL
SELECT 2 AS id, 'beta' AS name, CAST(20.00 AS DECIMAL(18,2)) AS amount;

-- 5) SparkThrift / Spark SQL 相邻回归表：无分区字段的普通 Spark 表
CREATE TABLE IF NOT EXISTS hotfix_150419_no_partition_cols (
  id       BIGINT COMMENT '主键',
  name     STRING COMMENT '名称',
  amount   DECIMAL(18,2) COMMENT '金额'
)
COMMENT 'hotfix 150419：无分区字段的普通 Spark 表'
STORED AS PARQUET;

INSERT OVERWRITE TABLE hotfix_150419_no_partition_cols
SELECT 1 AS id, 'gamma' AS name, CAST(30.50 AS DECIMAL(18,2)) AS amount
UNION ALL
SELECT 2 AS id, 'delta' AS name, CAST(40.00 AS DECIMAL(18,2)) AS amount;

-- 6) SQL 侧确认相邻回归表已存在
SHOW TABLES LIKE 'hotfix_150419_mixed_partition_cols';
SHOW TABLES LIKE 'hotfix_150419_no_partition_cols';
DESCRIBE hotfix_150419_mixed_partition_cols;
DESCRIBE hotfix_150419_no_partition_cols;
```

| 1 | 进入【数据资产 > 元数据管理 > 元数据同步】，点击【新增周期同步任务】或【新增同步任务】 | 弹出同步任务配置页面，页面加载正常 |
| 2 | 选择已接入的 SparkThrift / Spark 数据源，数据库选择前置条件中使用的测试库，同步范围选择 `hotfix_150419_all_partition_cols` | 目标库和目标表可被正常选择，不提示表不存在 |

| 5 | 查看同步实例日志，搜索关键词「表不存在」「同步表结构时异常，请确认表是否存在」 | 日志中不出现上述错误；不再出现 Bug #150419 中的失败信息 |

| 11 | 打开 `hotfix_150419_no_partition_cols` 表详情查看字段列表 | 普通字段 `id`、`name`、`amount` 均展示正确，不额外产生分区字段 |
