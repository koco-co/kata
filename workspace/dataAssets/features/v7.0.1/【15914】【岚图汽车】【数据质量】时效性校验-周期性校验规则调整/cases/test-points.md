## 不覆盖清单

| 测试点 | 不覆盖原因 | PRD 依据 |
| --- | --- | --- |
| 及时性校验（多字段时间差校验）及其他规则类型 | 需求范围仅包含时效性校验的周期性校验（单字段时间差校验） | PRD 范围 |
| Hive2.x、Hive3.x(Apache)、Doris2.x 的重复全量数据源矩阵 | 以 SparkThrift2.x 代表通用路径、Doris3.x 代表 Doris 专用转换路径，避免对同类实现做重复穷举 | BR-003, AC-008 |
| 窗口函数、时间转换与 SQL 模板的具体实现 | 属于低层实现细节，以 UI 可观察的分组结果、违规组合和明细记录验收 | FR-002, BR-003 |
| 脏数据物理表结构和落库内部字段 | 需求只要求在实例详情查看违规明细及字段颜色，不要求验收内部存储结构 | FR-005, FR-006 |
| 运行失败后的修复、重试与恢复流程 | 已确认范围只要求稳定构造运行失败并验证日志可查看、可定位原因 | PD-001, AC-004 |
