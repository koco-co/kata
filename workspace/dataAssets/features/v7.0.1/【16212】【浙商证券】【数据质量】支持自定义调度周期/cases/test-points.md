# 支持自定义调度周期 测试点

## 覆盖清单

| ID | 测试点 | 类型 | 优先级 | PRD 依据 |
| --- | --- | --- | --- | --- |
| TP-001 | 单表校验规则调度属性「调度周期」下拉提供「自定义调度日期」且位于「月」与「手动触发」之间；选择后展示自定义调度日期选择器与「预览」入口 | 正常 | P0 | FR-001, FR-002 |
| TP-002 | 选择「年月日」格式自定义调度日期时展示「具体时间」配置；选择「年月日时分」格式时不展示「具体时间」 | 正常 | P0 | FR-003, AC-003 |
| TP-003 | 未选择自定义调度日期时「预览」不可用，点击「保存」被阻止并提示必填 | 异常 | P1 | FR-002, BR-002 |
| TP-004 | 选择自定义调度日期后点击「预览」，展示所选日历的调度日期网格与最后一次调度时间 | 正常 | P1 | FR-004 |
| TP-005 | 多表比对规则调度属性同样提供「自定义调度日期」选项 | 正常 | P1 | FR-001 |
| TP-006 | 配置「年月日」格式自定义调度日期的质量任务，在日历命中的日期生成并运行任务实例（按「具体时间」执行） | 正常 | P0 | FR-005, FR-006, AC-001 |
| TP-007 | 配置「年月日时分」格式自定义调度日期的质量任务，按日历的日期+时间生成并运行任务实例 | 正常 | P1 | FR-005, FR-006, AC-001 |
| TP-008 | 日历未命中的日期不生成任务实例 | 边界 | P0 | FR-005, AC-002 |
| TP-009 | 运行中的任务实例点击「停止」并确认后，状态流转「中途停止」，操作列展示「运行」，表/任务名称不可点击 | 正常 | P1 | AC-005 |
| TP-010 | 任务查询「状态」筛选「中途停止」，列表仅展示中途停止状态的任务实例 | 正常 | P1 | AC-005 |
