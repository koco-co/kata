# 支持自定义脏数据存储字段 测试点

## 覆盖策略

以公共字段配置管理、项目信息生效开关、质量规则明细字段矩阵、规则任务配置快照、落标检查和权限六条路径覆盖需求。质量规则逐一覆盖固定字段规则、其余全部字段规则以及多表数据内容比对的主键双分支；任务快照覆盖公共字段新增、编辑、删除后“未编辑任务继续旧快照、编辑保存后新实例生效、历史实例不变”。数据源按需求范围仅覆盖 SparkThrift2.x。

## 不覆盖清单

| 测试点 | 不覆盖原因 | PRD 依据 |
| --- | --- | --- |
| 对历史任务实例批量回填新增字段或裁剪已删除字段 | PD-001 明确历史明细保持生成时状态 | PD-001, BR-005 |
| 源表字段删除、重命名或类型变化后的配置漂移处理 | PRD 明确本需求不定义该行为 | 异常、边界与兼容性 |
| 并发保存同一数据表配置时的冲突处理与提示文案 | PRD 明确本需求不定义并发行为 | 异常、边界与兼容性 |
| 通用网络、鉴权过期或服务不可用时的统一错误提示 | 属于平台通用异常，PRD 未新增特定行为 | 异常、边界与兼容性 |
| 多个管理员并发切换生效项目时的冲突提示或最后写入规则 | PRD 仅定义“最多一个项目生效”的结果，未定义并发冲突交互；不臆造提示文案 | 异常、边界与兼容性 |
| SparkThrift2.x 以外的数据源兼容矩阵 | 用户于 2026-08-11 明确本需求只使用 SparkThrift2.x | FR-004, AC-001 |
