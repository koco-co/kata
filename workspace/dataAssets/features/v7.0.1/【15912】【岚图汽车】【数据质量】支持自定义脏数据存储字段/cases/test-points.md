# 支持自定义脏数据存储字段 测试点

## 覆盖策略

以公共字段配置管理、普通质量规则、固定字段型质量规则、落标检查和权限五条路径覆盖需求。字段集合分别验证未配置、完全不重叠、部分重叠和全部重叠；普通质量规则与落标检查均覆盖四种集合状态，固定字段型规则单独验证不扩展行为。数据源选择覆盖蓝湖示例中的 SparkThrift2.x 与 Doris3.x。

## 不覆盖清单

| 测试点 | 不覆盖原因 | PRD 依据 |
| --- | --- | --- |
| 对历史任务实例批量回填新增字段或裁剪已删除字段 | PD-001 明确历史明细保持生成时状态 | PD-001, BR-005 |
| 源表字段删除、重命名或类型变化后的配置漂移处理 | PRD 明确本需求不定义该行为 | 异常、边界与兼容性 |
| 并发保存同一数据表配置时的冲突处理与提示文案 | PRD 明确本需求不定义并发行为 | 异常、边界与兼容性 |
| 通用网络、鉴权过期或服务不可用时的统一错误提示 | 属于平台通用异常，PRD 未新增特定行为 | 异常、边界与兼容性 |
| 逐一穷举全部内置质量子规则重复验证公共字段合并 | PRD 将行为划分为普通规则与固定字段型规则，本测试点按行为类别选代表规则覆盖 | BR-002, BR-003, AC-002 |
| 蓝湖未枚举的数据源类型全量兼容矩阵 | 测试点覆盖原型明确出现的 SparkThrift2.x 与 Doris3.x，其余类型没有需求证据 | FR-004, AC-001 |
