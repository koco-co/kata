# 支持自定义脏数据存储字段

## 需求身份与来源

- 需求 ID：15912
- 蓝湖文档：资产V7.0.0～7.0.2（岚图/泸州老窖定制）
- 文档 ID：`6e513ee1-fb7f-4e60-897a-21af81c65aba`
- 版本 ID：`6df27b45-b95e-4c3e-b79c-30515d3f4292`
- 页面 ID：`a94fe02759374acfb274aa9bfa7a2351`
- 8.7 补充：用户于 2026-08-10 提供“项目管理-项目信息”需求描述和页面截图；其中未由蓝湖原件明确的状态与时序语义，见 `PD-003` 至 `PD-006`。
- 8.11 补充：用户于 2026-08-11 明确质量规则的明细字段矩阵和任务级配置快照语义，见 `PD-007`、`BR-002`、`BR-003`、`BR-005`。

## 背景、目标与成功标准

岚图 SOW 外需求。允许按数据表配置脏数据公共字段，使任务执行后保存的明细字段能够在各子规则默认保存字段基础上补充业务定位字段。

## 范围

包含脏数据管理新增‘脏数据明细’页签、公共字段配置的列表与新建编辑删除详情、权限配置，以及公共字段对质量规则和落标检查规则的存储效果；新增项目管理-项目信息的“对落标检查生效”开关。按 `PD-001`、`PD-005`、`PD-007`，不包含对历史任务实例明细字段的回填或裁剪，也不包含公共字段配置变更后自动刷新既有规则任务。

## 角色、权限与前置条件

脏数据管理下新增‘脏数据明细’和‘脏数据存储’子级权限；两项默认授权管理员和数据开发，并可配置管理员、数据开发、访客。项目管理-项目信息的生效开关沿用现有数据质量项目管理权限，不新增独立权限点。执行效果以开启脏数据存储且任务可生成明细为前置条件。

## 现状与变更

现有‘脏数据存储’页签按数据源管理独立存储；当前 6.3 岚图 release 在通用路径中按源表字段创建脏数据表。本需求新增‘脏数据明细’页签，按数据表维护公共字段，并把目标明细字段收敛为子规则默认保存字段与公共字段的规则化集合。8.7 补充在项目管理-项目信息列表增加“对落标检查生效”开关，用唯一的生效项目为落标检查选择公共字段来源。

## 8.7 补充需求：项目管理-项目信息

项目列表新增“对落标检查生效”列及开关。提示文字为：“开启后，该项目下脏数据明细中配置的公共字段将对落标检查结果生效，仅支持开启一个项目。”开启一个项目时，其余项目自动关闭；可以关闭当前生效项目而回到全关闭。切换生效项目不处理历史脏数据，只影响后续新数据。

## 业务场景

用户可搜索、筛选、排序并维护表级公共字段；点击数据表名称查看数据源、数据库和公共字段详情；具备数据质量项目管理权限的用户可在项目信息中选择最多一个落标检查生效项目；任务执行后在质量规则或落标检查的不通过明细中验证实际保存字段。

## 字段、枚举、校验与错误

脏数据明细列表展示数据表、数据源、数据库、公共字段、更新人、最近更新时间和操作；公共字段文本超过 25 个字符时省略。新建时数据源、数据库、数据表单选，公共字段多选；已配置的数据表从可选列表过滤。字段类型从数据源表获取。按 `PD-002`，公共字段至少选择 1 个，未选择或编辑后清空全部字段时阻断保存并提示选择字段。项目信息列表新增“对落标检查生效”列，提示文字使用 8.7 补充需求给定文案。

## 状态与数据规则

表已配置公共字段时，除固定字段规则外的质量规则明细展示源表全部字段；未配置时仍按子规则默认字段展示。固定字段规则包括枚举值校验、多表数据一致性、多表字段值对比校验、多表数据行数对比和自定义 SQL，这些规则不因公共字段配置而扩展。多表数据内容比对按“校验表主键”分支处理：选择校验表主键时只展示规则固定字段，未选择时展示源表全部字段。

规则任务保存时快照当时的公共字段配置及对应明细字段策略。公共字段配置新增、编辑或删除后，未重新编辑保存的既有任务继续按旧快照执行；只有编辑并保存任务后，后续新实例才使用最新配置。任务编辑前后的历史实例均保持生成时字段，不回填、不裁剪。

落标检查只读取唯一生效项目中与当前校验表匹配的公共字段配置，并与落标检查字段去重合并；其他项目的配置不生效。没有生效项目，或生效项目未配置当前校验表时，只保存落标检查字段。启用项目 B 会自动关闭项目 A；直接关闭 B 后回到全关闭。每次落标检查在启动时快照生效项目及字段集合，切换只影响其后启动的检查。

## 异常、边界与兼容性

覆盖公共字段未选择、与默认字段完全不重叠、部分重叠和全部重叠，固定字段规则与全字段规则矩阵，多表数据内容比对是否选择校验表主键的分支，以及已配置表过滤。按 `PD-001`、`PD-007`，配置新增、编辑和删除不会自动刷新既有规则任务；任务编辑保存后仅后续新实例使用最新字段策略，历史任务实例保持原明细字段。按 `PD-005`，切换生效项目不改变已经启动或已经生成的落标检查明细；按 `PD-006`，删除当前生效项目时自动回到全关闭。源表后续发生字段删除、重命名或类型变更后的配置漂移、并发切换生效项目的冲突处理，以及通用网络失败提示均无需求证据，本需求不定义这些行为。

## 依赖与影响

影响数据质量项目管理菜单和权限、表与字段元数据查询、脏数据建表或写入字段、质量规则明细、落标检查不达标详情。当前 6.3 岚图 release 尚无本需求实现。

## 已确认的产品决策

### PD-001 公共字段配置不追溯历史明细

历史任务实例保持生成时已落盘的字段，不回填、不裁剪；公共字段配置如何进入后续规则任务，按 `PD-007` 的任务级配置快照执行。

来源：`Q-001`、`lanhu:a94fe02759374acfb274aa9bfa7a2351`

### PD-002 公共字段配置不能为空

新建或编辑配置时必须至少选择 1 个公共字段；未选择或清空全部字段时阻断保存并提示选择字段。恢复为仅保存规则默认字段时，应删除整条表配置。

来源：`Q-002`、`lanhu:a94fe02759374acfb274aa9bfa7a2351`

### PD-003 落标检查可处于全关闭

“对落标检查生效”最多开启一个项目，允许直接关闭当前生效项目。没有生效项目时，后续落标检查不追加任一项目的公共字段，只保存落标检查自身字段。

来源：`Q-003`、`Q-004`、`用户补充-2026-08-10`

### PD-004 落标检查使用全局唯一项目来源

生效项目是所有后续落标检查的全局唯一公共字段来源：仅读取该项目中与当前校验表匹配的配置，其他项目配置一律不生效。普通质量规则维持所在项目的既有公共字段行为。

来源：`Q-005`、`用户补充-2026-08-10`

### PD-005 落标检查在启动时快照字段集合

落标检查启动时快照当时的生效项目和匹配公共字段。检查启动后即使切换生效项目，当前执行仍使用启动时快照；新项目仅影响切换后新启动的检查，历史明细不回填、不裁剪。

来源：`Q-006`、`用户补充-2026-08-10`

### PD-006 删除生效项目回到全关闭

删除当前唯一生效项目成功后，系统自动清空生效状态；后续落标检查按全关闭规则只保存自身字段，历史明细保持不变。

来源：`Q-007`、`用户补充-2026-08-10`

### PD-007 规则任务使用编辑保存时的公共字段快照

规则任务创建或编辑保存时快照公共字段配置及对应明细字段策略。公共字段配置新增、编辑或删除后，直接再次执行未编辑任务仍使用旧快照；编辑并保存该任务后，后续新实例才使用最新配置。任务编辑前后的历史实例均保持生成时字段。

来源：`用户补充-2026-08-11`

## 验收标准

AC-001 公共字段配置可查询和维护、空字段配置被阻断且列表行为符合蓝湖；AC-002 固定字段规则、全字段规则、多表数据内容比对主键分支及落标检查均生成正确的明细字段集合；AC-003 子级权限的默认授权和可配置角色符合蓝湖；AC-004 公共字段配置变更不会自动刷新既有规则任务，任务编辑保存后仅后续实例使用最新字段策略且历史明细保持不变；AC-005 项目信息开关和提示文字正确，任意时刻最多一个项目生效且可全关闭；AC-006 生效项目切换、执行快照和删除生效项目均只影响后续落标检查数据。
