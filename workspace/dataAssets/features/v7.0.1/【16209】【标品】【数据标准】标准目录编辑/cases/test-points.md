# 标准目录编辑测试点

## 覆盖清单

| ID | 测试点 | 类型 | 优先级 | PRD 依据 |
| --- | --- | --- | --- | --- |
| TP-001 | 已上线标准展示「修改目录」操作；点击后弹出「修改目录」弹窗，弹窗仅提供必填的「标准目录」选择项及「取消」「保存」按钮 | 正常 | P0 | FR-001, FR-002, BR-001, BR-002 |
| TP-002 | 将已上线标准从原目录修改至另一目录并保存，提示「标准目录保存成功」；标准详情、原目录筛选和新目录筛选结果同步更新 | 正常 | P0 | FR-002, BR-001, AC-001, AC-002 |
| TP-003 | 修改目录保存后立即生效，标准始终保持「已上线」 | 正常 | P0 | PD-001 |
| TP-004 | 修改目录后新增一条标准版本记录，版本对比仅显示标准目录由原目录变为新目录，其他字段无差异 | 正常 | P1 | PD-002, AC-003 |
| TP-005 | 在修改目录弹窗选择另一目录后点击「取消」或关闭弹窗，原目录、标准状态和版本记录均不变化 | 边界 | P1 | FR-002, BR-001 |
| TP-006 | 标准目录未选择时保存被阻止，并在「标准目录」字段提示必填校验 | 异常 | P1 | BR-002 |
| TP-007 | 待上线和待审批标准不提供「修改目录」操作，仍沿用各自现有操作集合 | 边界 | P1 | FR-001, PD-001 |
| TP-008 | 无数据标准操作权限的用户不能执行「修改目录」，且无法绕过页面权限完成目录变更 | 异常 | P1 | BR-003 |

## 不覆盖清单

| 测试点 | 不覆盖原因 | PRD 依据 |
| --- | --- | --- |
| 批量修改多个标准的所属目录 | 本需求仅包含单条已上线标准的目录修改 | 范围 |
| 通过修改目录入口编辑标准名称、编码、业务属性或技术属性 | 修改目录仅允许变更所属目录 | BR-001 |
| 新增、重命名、移动或删除标准目录节点 | 标准目录树维护不属于本需求 | 范围 |
| 迁移或修复历史标准目录数据 | 历史数据迁移不属于本需求 | 范围 |
| 网络中断、接口失败、并发修改或目标目录被并发删除时的提示与恢复策略 | PRD 未定义具体失败提示、重试和冲突处理规则 | 无（PRD 未定义） |
