##### 【P1】范围分区 验证选择手动输入分区，表分区内数据校验异常

> 前置条件

```
已引入数据源，且包含库表，表内包含数据
建表语句：
DROP TABLE IF EXISTS test_doris_03;
CREATE TABLE test_doris_03 (
id INT,
name STRING,
age INT
)
PARTITION BY RANGE (age) (
PARTITION p1 VALUES LESS THAN ("18"),
PARTITION p2 VALUES LESS THAN ("30"),
PARTITION p3 VALUES LESS THAN ("40"),
PARTITION p4 VALUES LESS THAN ("50"),
PARTITION pmax VALUES LESS THAN (MAXVALUE)
)
DISTRIBUTED BY HASH(id) BUCKETS 3;
表插入语句：
INSERT INTO test_doris_03 VALUES (1, 'Alice', 25);   -- p1
INSERT INTO test_doris_03 VALUES (1, 'Alice',   25);   -- p2
INSERT INTO test_doris_03 VALUES (3, 'Charlie', 35); -- p3
INSERT INTO test_doris_03 VALUES (4, 'David', 45);   -- p4
INSERT INTO test_doris_03 VALUES (5, 'Eva',   60);   -- pmax
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 规则集管理】页面，点击【新建规则集】，选择数据源「测试数据源_Doris」、数据库「quality_test_db」、数据表「test_doris_03」，新增规则包「唯一性校验规则包」，点击【下一步】 | 进入 Step 2【监控规则】页面，规则集「weiyi_07_规则集」的规则包「唯一性校验规则包」可配置。 |
| 2 | 在 Step 2【监控规则】中点击【新增规则】，选择「唯一性校验」，按以下参数完成规则配置并保存：<br>输入<br>选择校验字段逻辑：唯一<br>选择和其他表的校验关系：且<br>选择对比表：test_doris_03<br>选择对比表字段：id、name<br>输入分区：手动输入分区-age=25<br>选择校验字段逻辑：唯一<br>点击保存、下一步<br>保存规则后点击页面底部【保存】 | 规则集保存成功，规则包「唯一性校验规则包」中存在本用例需要的「唯一性校验」规则。 |
| 3 | 进入【数据质量 → 规则任务管理】页面，点击【新建监控规则】，在 Step 1【监控对象】填写以下内容后点击【下一步】：<br>输入<br>规则名称：weiyi_07<br>选择数据源：测试数据源_Doris<br>选择数据库：quality_test_db<br>选择数据表：test_doris_03<br>点击下一步 | 进入 Step 2【监控规则】页面，监控对象与规则集所属数据表一致。 |

| 5 | 在 Step 3【调度属性】页保持默认调度配置，实例生成方式选择【立即生成】，点击【保存】 | 规则任务「weiyi_07」保存成功，并出现在规则任务列表中。 |
