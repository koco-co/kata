## 资产盘点
### 资产盘点
##### 【P3】验证首次进入时弹出【欢迎使用】引导弹窗

> 前置条件

- 已登录系统，具备【资产 → 资产盘点】访问权限。
- 引导配置未设置为【不再提示】。

> 操作步骤

1. 访问 `【/assetsStatistics】` 进入【资产盘点】。
2. 观察页面是否出现半屏弹窗，弹窗标题为【欢迎使用】。
3. 在弹窗中勾选【不再提示】复选框。
4. 点击弹窗右下角【知道了】按钮。
5. 关闭并重新打开页面。

> 预期结果

1. 首次访问时弹出引导弹窗，标题、说明与引导内容可见。
2. 点击【不再提示】后，配置接口返回成功，`【不再提示】`状态可见为已选。
3. 点击【知道了】后弹窗关闭且页面继续展示【资产盘点】内容。
4. 在未清理引导设置的前提下再次进入页面，不再弹出引导弹窗。

##### 【P1】验证【已接入数据源】区域展示已接入数据源统计卡片

> 前置条件

- 已登录系统并具备【资产 → 资产盘点】访问权限。
- 已同步数据源并存在测试数据库/表。

```sql
DROP DATABASE IF EXISTS qa_inventory;
CREATE DATABASE qa_inventory;
DROP TABLE IF EXISTS qa_inventory.inventory_sales;
CREATE TABLE qa_inventory.inventory_sales USING SPARKTHRIFT2X AS
SELECT 1 AS id, 'finance' AS dept, 'alice' AS owner, 120 AS rec_count
UNION ALL SELECT 2 AS id, 'finance' AS dept, 'alice' AS owner, 80 AS rec_count
UNION ALL SELECT 3 AS id, 'ops' AS dept, 'bob' AS owner, 60 AS rec_count;
DROP TABLE IF EXISTS qa_inventory.inventory_profile;
CREATE TABLE qa_inventory.inventory_profile USING SPARKTHRIFT2X AS
SELECT 1 AS id, 'finance' AS catalog, 'inventory_sales' AS table_name, '活跃' AS `status`
UNION ALL SELECT 2 AS id, 'ops' AS catalog, 'inventory_profile' AS table_name, '活跃' AS `status`;
```

> 操作步骤

1. 进入【资产盘点】页面。
2. 查看页面顶部【已接入数据源】卡片区域。
3. 确认至少存在一张数据源卡片且可见【昨日新增】字段。

> 预期结果

1. 区块展示来自【/dassets/v1/assetsStatistics/dataPreview】接口返回的卡片数据。
2. 每张卡片显示对应数据源名称、【昨日新增】及相关统计字段。
3. 在【数据源总数】> 当前可展示张数时，顶部区域渲染完整。

##### 【P2】验证【数据地图分布】支持切换【数据源】与【分布属性】

> 前置条件

- 已登录系统并具备【资产 → 资产盘点】访问权限。
- 已按上条用例准备 `qa_inventory` 库。

> 操作步骤

1. 在【数据地图分布】区块点击【数据源】下拉，选择不同数据源类型。
2. 在【分布属性】下拉切换为其他属性项。
3. 观察左侧饼图与右侧排行榜。
4. 重复更换【数据源】与【分布属性】各一次。

> 预期结果

1. 每次选择变化后，饼图与对应统计表刷新，表头与数据一致。
2. 【排序】列保留序号、表数量、表占比等列内容且未出现空值错误。
3. 切换结果对应当前选择条件，没有固定死数据。

##### 【P2】验证【数据价值排行】支持时间范围切换与多字段排序

> 前置条件

- 已登录系统并具备【资产 → 资产盘点】访问权限。
- 已准备 `qa_inventory` 测试数据。

> 操作步骤

1. 在【数据价值排行】区块选择【近1个月】。
2. 在同一区块切换【近1年】。
3. 在列表中分别点击【查看次数】、【使用次数】、【影响表数】列标题。

> 预期结果

1. 切换时间范围后表格内容按 `interval` 重新查询返回。
2. 每个可排序列点击后列表按对应字段升序/降序排列。
3. 默认列表展示可见并包含【表名】、【数据库】及排行序号。

##### 【P1】验证已发布的【资产影响统计】任务可手动触发并返回成功

> 前置条件

- 已登录系统，具备触发任务调度权限。
- 令牌或会话保持有效。

> 操作步骤

1. 执行以下命令触发任务：
```bash
curl -X POST "${BASE_URL}/dassets/v1/scheduleJob/affectCountStatistic"
```

2. 记录接口返回状态与内容。

> 预期结果

1. 接口返回成功状态码，`success` 为 `true`。
2. 返回内容包含任务触发成功或任务 ID，可供后续查询。
3. 接口无 5xx/错误码，能够继续进行页面数据刷新或下游统计更新。
