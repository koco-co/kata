## 数据质量

### 通用配置-json格式校验管理

#### 勾选导出

##### 【P0】验证勾选多条记录后点击导出，导出文件仅含勾选行

> 前置条件

```
json格式校验管理列表已存在以下一层级 key（数据源类型 SparkThrift2.x）：
- exportA（中文名称：导出测试A）
- exportB（中文名称：导出测试B）
- exportC（中文名称：导出测试C）
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 通用配置 → json格式校验管理】，等待列表数据加载完成 | 列表每行首列显示复选框，表头显示全选复选框；<br>顶部依次显示【导入】【导出】【新增】按钮；<br>所有行复选框初始均未勾选 |
| 2 | 勾选 exportA、exportB 两行复选框，不勾选 exportC | exportA、exportB 复选框变为选中态；<br>列表底部显示「当前选中：2」；<br>exportC 复选框仍为未选中态 |
| 3 | 点击顶部【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的导出文件，核对数据行与内容 | 文件仅含 exportA、exportB 两条记录，不含 exportC；<br>列按顺序为：key、中文名称、value格式、数据源类型、创建人、创建时间、更新人、更新时间、层级关系、父Key |

##### 【P0】验证勾选导出文件含「层级关系」与「父Key」列且取值正确

> 前置条件

```
json格式校验管理列表已存在以下层级结构（数据源类型 SparkThrift2.x）：
- 一层 key：parentExport（中文名称：父级导出）
- parentExport 下二层 key：childExport（中文名称：子级导出）
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 通用配置 → json格式校验管理】，等待列表数据加载完成 | 列表正常加载，每行显示复选框；<br>parentExport 行显示展开图标 |
| 2 | 点击 parentExport 行的展开图标展开子层级，勾选 parentExport 与 childExport 两行 | parentExport、childExport 两行均为选中态；<br>列表底部显示「当前选中：2」 |
| 3 | 点击顶部【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的导出文件，核对列结构与层级字段 | 列按顺序为：key、中文名称、value格式、数据源类型、创建人、创建时间、更新人、更新时间、层级关系、父Key；<br>parentExport 行「层级关系」为「一层」、「父Key」为空；<br>childExport 行「层级关系」为「二层」、「父Key」为 parentExport |

##### 【P1】验证仅勾选单条一层级记录导出，文件仅含该条记录

> 前置条件

```
json格式校验管理列表已存在一层级 key：singleExport（中文名称：单行导出，value格式：^\d+$，数据源类型 SparkThrift2.x）
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 通用配置 → json格式校验管理】，等待列表数据加载完成 | 列表正常加载，每行显示复选框 |
| 2 | 仅勾选 singleExport 一行复选框 | 仅 singleExport 行为选中态，其余行未选中；<br>列表底部显示「当前选中：1」 |
| 3 | 点击顶部【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的导出文件，核对记录条数与字段值 | 文件仅含 1 条记录：<br>key=singleExport，中文名称=单行导出，value格式=^\d+$，数据源类型=SparkThrift2.x，层级关系=一层，父Key=空 |

##### 【P1】验证勾选父节点时子节点不被自动级联进导出文件

> 前置条件

```
json格式校验管理列表已存在以下层级结构（数据源类型 SparkThrift2.x）：
- 一层 key：parentOnly（中文名称：仅导出父节点）
- parentOnly 下二层 key：childNotExport（中文名称：不应出现在导出中）
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 通用配置 → json格式校验管理】，等待列表数据加载完成 | 列表正常加载，parentOnly 行显示展开图标 |
| 2 | 不展开 parentOnly，仅勾选 parentOnly 一行复选框 | 仅 parentOnly 行为选中态；<br>列表底部显示「当前选中：1」 |
| 3 | 点击顶部【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的导出文件，核对记录条数 | 文件仅含 parentOnly 一条记录，不含 childNotExport；<br>说明勾选父节点不会自动级联导出其子节点 |

##### 【P1】验证表头全选后点击导出，文件含当前列表全量数据

> 前置条件

```
json格式校验管理列表已存在至少 2 条一层级 key（数据源类型 SparkThrift2.x），总条数不超过单页容量
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 通用配置 → json格式校验管理】，等待列表数据加载完成 | 列表正常加载，表头显示全选复选框，每行显示复选框 |
| 2 | 点击表头的全选复选框 | 当前页所有行复选框变为选中态，表头复选框变为全选态；<br>列表底部「当前选中」计数等于当前页行数 |
| 3 | 点击顶部【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的导出文件，与列表数据逐行对比 | 导出文件记录条数与全选的可见行数一致；<br>各行 key、中文名称、value格式、数据源类型与列表显示一致 |

##### 【P1】验证未勾选任何记录时点击导出，沿用导出全量旧行为

> 前置条件

```
json格式校验管理列表已存在多条 key 记录（数据源类型 SparkThrift2.x），页面初始无任何行被勾选
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 通用配置 → json格式校验管理】，等待列表数据加载完成 | 所有行复选框均未勾选；<br>顶部【导出】按钮可点击（未置灰） |
| 2 | 不勾选任何行，直接点击顶部【导出】按钮，等待文件下载完成 | 【导出】按钮在零勾选状态下仍可点击；<br>浏览器触发文件下载 |
| 3 | 打开下载的导出文件，与列表当前全部数据对比 | 文件含当前列表（或当前搜索结果）全部记录；<br>验证零勾选时沿用「导出全部数据」旧行为，不受勾选导出影响 |

##### 【P2】验证先搜索筛选再勾选导出，文件仅含搜索结果中勾选的行

> 前置条件

```
json格式校验管理列表已存在 key 名含 "vehicle" 的记录与不含 "vehicle" 的其他记录（数据源类型 SparkThrift2.x）
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 通用配置 → json格式校验管理】，等待列表数据加载完成 | 列表正常加载，顶部显示搜索框「请输入key名称查询」 |
| 2 | 在搜索框输入 vehicle，触发查询，等待列表刷新 | 列表仅显示 key 名含 vehicle 的记录 |
| 3 | 勾选搜索结果中的 1 行，点击顶部【导出】按钮，等待文件下载完成 | 该行复选框选中，列表底部显示「当前选中：1」；<br>浏览器触发文件下载 |
| 4 | 打开下载的导出文件，核对记录 | 文件仅含步骤 3 勾选的那行记录，不含未勾选的其它 vehicle 记录，也不含被搜索过滤掉的记录 |

##### 【P1】验证跨分页勾选后导出，文件含各页已勾选记录

> 前置条件

```
json格式校验管理列表一层级 key 条数超过单页容量（每页 10 条则准备 ≥ 12 条，命名便于识别，如 pageOne01…、pageTwo01…，数据源类型 SparkThrift2.x），确保列表至少分为 2 页
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| 1 | 进入【数据质量 → 通用配置 → json格式校验管理】，等待列表数据加载完成 | 列表正常加载，底部分页区显示总条数与页码，当前为第 1 页 |
| 2 | 在第 1 页勾选 1 行（如 pageOne01） | 该行复选框选中；<br>列表底部显示「当前选中：1」 |
| 3 | 通过分页区切换到第 2 页，勾选第 2 页 1 行（如 pageTwo01） | 列表切换至第 2 页并加载完成；<br>勾选 pageTwo01 后底部累计显示「当前选中：2」，验证跨页勾选态被保留、未在翻页时清空 |
| 4 | 点击顶部【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 5 | 打开下载的导出文件，核对记录 | 文件同时含第 1 页勾选的 pageOne01 与第 2 页勾选的 pageTwo01 两条记录，不含两页中未勾选的其它记录 |
