## 数据质量

### 通用配置-json格式校验管理

#### 勾选导出

##### 【P0】验证勾选多条记录后点击导出，文件仅包含勾选行数据

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中已存在至少3条一层级数据（如 exportA、exportB、exportC），其中 exportA 含子层级 exportA-child
3) 版本为 6.3 岚图定制分支，列表已支持行复选框
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 页面标题显示「json格式校验管理」，列表每行首列显示复选框，均为未勾选状态 |
| 2 | 勾选 exportA 和 exportB 两行的复选框（不勾选 exportC） | 两行复选框变为选中状态，列表上方出现已选条数提示（如「已选2条」）；exportC 未被选中 |
| 3 | 点击列表右上角【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的 xlsx 文件，检查数据行数和内容 | 文件仅包含 exportA 和 exportB 两条记录，不含 exportC；列按顺序为：key、中文名称、value格式、数据源类型、创建人、创建时间、更新人、更新时间、层级关系、父Key |

##### 【P0】验证勾选导出文件的列结构包含「层级关系」与「父Key」列

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理中已存在以下层级结构：
   - 一层 key: parentExport（中文名称：父级导出测试，value格式：^[a-z]+$，数据源类型：SparkThrift2.x）
   - 二层 key: childExport（父级为 parentExport，中文名称：子级导出测试）
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，每行显示复选框 |
| 2 | 勾选一层级 parentExport 行，展开 parentExport 后再勾选二层级 childExport 行 | parentExport 和 childExport 两行均显示选中状态 |
| 3 | 点击【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的 xlsx 文件，检查列结构和层级字段 | 列按顺序为：key、中文名称、value格式、数据源类型、创建人、创建时间、更新人、更新时间、层级关系、父Key；parentExport 行「层级关系」为「一层」、「父Key」为空；childExport 行「层级关系」为「二层」、「父Key」为 parentExport |

##### 【P1】验证勾选父节点时子节点不被自动级联到导出文件

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理中已存在以下层级结构：
   - 一层 key: parentOnly（中文名称：仅导出父节点）
   - 二层 key: childNotExport（父级为 parentOnly，中文名称：不应出现在导出中）
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，parentOnly 行显示「+」展开图标 |
| 2 | 仅勾选 parentOnly 一行（不展开，不勾选子层级 childNotExport） | 仅 parentOnly 行复选框选中 |
| 3 | 点击【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的 xlsx 文件，检查记录条数 | 文件仅包含1条记录（parentOnly），不包含 childNotExport，说明父节点勾选不自动级联至子节点 |

##### 【P1】验证未勾选任何记录时导出按钮置灰不可点击

> ⚠️ 需求待确认：PRD 仅定义「勾选行→导出勾选行」，未规定零勾选行为。本用例按「勾选导出」功能的常规交互固定预期为「按钮置灰」；若产品实际实现为「零勾选时导出全量」，本用例将失败并暴露需求缺口，需据 PM 反馈调整预期。

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中已存在至少1条数据
3) 版本为 6.3 岚图定制分支
4) 页面初始状态：无任何行被勾选
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，所有行复选框均未勾选 |
| 2 | 在无任何行勾选的状态下，查看列表右上角【导出】按钮状态 | 【导出】按钮处于置灰禁用状态（disabled），无法点击触发导出 |
| 3 | 鼠标悬停在置灰的【导出】按钮上 | 出现 Tooltip 提示「请先勾选要导出的数据」或同义文案 |
| 4 | 勾选任意1行后再次查看【导出】按钮 | 【导出】按钮由置灰变为可点击状态 |

##### 【P2】验证勾选状态在搜索或筛选操作前后的一致性

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中已存在数据，包含 key 名含 filterTest 的记录和其他记录
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，所有行复选框未勾选 |
| 2 | 勾选列表中1条记录 | 该行复选框变为选中状态 |

| 4 | 清空搜索框，等待列表恢复完整显示 | 核对原先勾选行的选中状态在搜索前后是否保持一致，验证勾选态不被搜索误清或误留 |

##### 【P1】验证跨分页勾选后导出，文件包含各页已勾选记录

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中一层级数据条数超过单页容量（如每页 10 条则准备 ≥ 12 条），确保至少分为2页
   （可批量新增或导入，命名便于识别：pageOne01…、pageTwo01… 等）
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，底部分页组件显示总条数与页码，当前为第1页 |
| 2 | 在第1页勾选 1 条记录（如 pageOne01） | 该行复选框选中，已选条数提示显示「已选1条」 |
| 3 | 点击分页组件切换到第2页，勾选第2页 1 条记录（如 pageTwo01） | 列表切换至第2页并加载完成；勾选 pageTwo01 后，已选条数提示累计为「已选2条」（验证跨页勾选态被保留，未在翻页时清空） |
| 4 | 点击【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 5 | 打开下载的 xlsx 文件，核对记录 | 文件同时包含第1页勾选的 pageOne01 和第2页勾选的 pageTwo01 两条记录，不含两页中未勾选的其他记录 |
