- 编码管理覆盖内置编码前缀、序号宽度、最大值、重置前存在未删除数据、删除后不复用和溢出继续递增。【蓝湖 13176】

- 自定义属性搜索条件覆盖最少 2 个、最多 8/9 个的需求版本规则；超出上限必须阻断。【蓝湖 13184】【禅道历史用例】

## 设计原则

- 正常流、异常流、边界全覆盖；枚举值逐项覆盖；P0 用例约占总量四分之一至三分之一。
- 以当前有效需求规则覆盖历史冲突：旧的“内置属性不可操作”预期不进入正式 YAML；安全等级/隐私等级的删除禁用由 13923 的最新规则覆盖。
- 由于 14050 原型中的红框表格无法从文本层读取具体字段值，只收录可由需求文字和历史用例确认的同步、顺序、必填、导入导出和全选行为，不臆造字段清单。
