## 数据质量

### 通用配置-json格式校验管理

#### 勾选导出

##### 【P0】验证勾选多条记录后点击导出，文件仅包含勾选行数据

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中已存在至少3条一层级数据（如 exportA、exportB、exportC），
   其中 exportA 含子层级 exportA-child
3) 版本为 6.3 岚图定制分支，列表已支持行复选框
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 页面标题显示「json格式校验管理」，列表每行首列显示复选框，未勾选状态 |
| 2 | 勾选 exportA 和 exportB 两行的复选框（不勾选 exportC） | 两行复选框变为选中状态，列表上方或右上角出现勾选状态提示（如「已选2条」）；exportC 未被选中 |
| 3 | 点击【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的 xlsx 文件，检查数据行数和内容 | 文件中仅包含 exportA 和 exportB 两条记录，不含 exportC；文件包含以下列（按顺序）：key、中文名称、value格式、数据源类型、创建人、创建时间、更新人、更新时间、层级关系、父Key |

##### 【P0】验证勾选导出文件列结构包含「父Key」字段

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理中已存在以下层级结构：
   - 一层 key: parentExport（中文名称：父级导出测试，value格式：^[a-z]+$，数据源类型：SparkThrift2.x）
   - 二层 key: childExport（父级为 parentExport，中文名称：子级导出测试）
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，每行显示复选框 |
| 2 | 勾选一层级 parentExport 行，展开 parentExport 后再勾选二层级 childExport 行 | parentExport 和 childExport 两行均显示选中状态 |
| 3 | 点击【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的 xlsx 文件，检查列结构和内容 | 文件包含 parentExport 和 childExport 两条记录；列顺序为：key、中文名称、value格式、数据源类型、创建人、创建时间、更新人、更新时间、层级关系、父Key；parentExport 行的「层级关系」为「一层」，「父Key」列为空；childExport 行的「层级关系」为「二层」，「父Key」列为 parentExport |

##### 【P1】验证勾选单条一层级记录后导出，文件仅含该条记录

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中已存在一层级 key：singleExportKey（中文名称：单行导出测试，value格式：^\d+$，数据源类型：Hive2.x）
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，每行显示复选框 |
| 2 | 仅勾选 singleExportKey 一行的复选框 | 仅该行复选框选中，其余行未选中 |
| 3 | 点击【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的 xlsx 文件，检查数据行数和字段值 | 文件仅包含1条记录：key=singleExportKey，中文名称=单行导出测试，value格式=^\d+$，数据源类型=Hive2.x，层级关系=一层，父Key=空 |

##### 【P1】验证勾选父节点时子节点不被自动包含在导出文件中

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理中已存在以下层级结构：
   - 一层 key: parentOnly（中文名称：仅导出父节点）
   - 二层 key: childNotExport（父级为 parentOnly，中文名称：不应出现在导出中）
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，parentOnly 行显示「+」展开图标 |
| 2 | 仅勾选 parentOnly 一行（不展开，不勾选子层级 childNotExport） | 仅 parentOnly 行复选框选中 |
| 3 | 点击【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的 xlsx 文件，检查记录条数 | 文件仅包含1条记录（parentOnly），不包含 childNotExport；说明父节点的勾选不自动级联至子节点 |

##### 【P1】验证全选后点击导出，文件包含列表当前全量数据

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中已存在至少2条一层级数据
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，表头行显示全选复选框，每行显示复选框 |
| 2 | 点击列表表头行的全选复选框 | 当前页所有一层级行的复选框变为选中状态，表头复选框变为选中（或全勾状态） |
| 3 | 点击【导出】按钮，等待文件下载完成 | 浏览器触发文件下载 |
| 4 | 打开下载的 xlsx 文件，与列表数据总数对比 | 导出文件包含的数据行数与当前全选的可见行数一致，数据内容与列表显示一致 |

##### 【P1】验证未勾选任何记录时导出按钮的交互行为

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中已存在至少1条数据
3) 版本为 6.3 岚图定制分支
4) 页面初始状态：无任何行被勾选
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，所有行复选框均未勾选 |
| 2 | 不勾选任何行，直接点击【导出】按钮 | （以下两种行为均可接受，以实际版本实现为准）<br>**方案A**：导出按钮处于不可点击状态（disabled），无法触发导出；<br>**方案B**：弹出确认弹窗，提示「未勾选任何数据，是否导出全量列表数据」，点击确认后导出所有数据 |
| 3 | 若出现方案A（按钮disabled）：尝试验证提示文案 | 鼠标悬停导出按钮时，出现 Tooltip 提示「请先勾选要导出的数据」或类似文案 |

##### 【P2】验证勾选状态在搜索或筛选操作后是否被重置

> 前置条件

```
1) 使用 admin 账号登录系统
2) json格式校验管理列表中已存在数据，包括 key 名含 filterTest 的记录和其他记录
3) 版本为 6.3 岚图定制分支
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ---- | ---- |
| 1 | 进入【数据质量 → 通用配置】页面，等待 json 格式校验管理列表数据加载完成 | 列表正常加载，所有行复选框未勾选 |
| 2 | 勾选列表中1条记录 | 该行复选框变为选中状态 |
| 3 | 在搜索框中输入 filterTest，等待列表筛选完成 | 列表仅显示 key 名含 filterTest 的记录；此时需观察原先勾选的行（若仍在列表中）的复选框状态是否保留，以及清空搜索后勾选状态是否恢复 |
| 4 | 清空搜索框，等待列表恢复完整显示 | 记录原先勾选的行是否仍保持选中状态（与产品实现对比，验证勾选状态在搜索前后的一致性） |
