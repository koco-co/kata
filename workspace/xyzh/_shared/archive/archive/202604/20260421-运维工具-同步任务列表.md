## 运维工具 - 同步任务列表

### 列表页

#### 页面初始化与权限

##### 【P0】验证有权限账号进入页面后正确展示任务列表与字段

> 前置条件
```
1) 使用具备【运维工具 → 同步任务列表】页面访问权限的账号登录系统。
2) 系统中已存在数据目录发布流程或数据标准制定流程审批通过的实例记录。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入【运维工具 → 同步任务列表】页面，等待列表加载完成 | 页面正常加载，列表展示 PRD 定义字段：业务流水号、流程类型、表单类型、审批通过时间、推送结果、推送失败原因、推送完成时间 |
| 2 | 查看列表中各条任务的「推送结果」列 | 推送结果取值仅在「进行中 / 成功 / 失败」三种之一；推送结果非「失败」时「推送失败原因」列为空 |

##### 【P1】验证无权限账号无法进入同步任务列表页面

> 前置条件
```
1) 使用不具备【运维工具 → 同步任务列表】页面权限的账号登录系统。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在左侧菜单查看【运维工具】子菜单，并通过 URL 直接访问该页面 | 菜单不显示「同步任务列表」入口；URL 直接访问被拦截或提示无权限 |

#### 字段与状态展示

##### 【P1】验证不同流程类型与表单类型的任务在列表中正确区分

> 前置条件
```
1) 使用具备页面访问权限的账号登录系统。
2) 列表中存在「数据目录发布流程」与「数据标准制定流程」两种流程类型的任务记录。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入【运维工具 → 同步任务列表】页面，等待列表加载完成 | 列表中存在多条任务，「流程类型」分别显示「数据目录发布流程」「数据标准制定流程」 |
| 2 | 查看不同流程类型任务对应的「表单类型」「业务流水号」 | 表单类型与对应流程类型一致；业务流水号与原流程实例一致 |

##### 【P1】验证推送进行中的任务不显示重试按钮

> 前置条件
```
1) 列表中存在一条「推送结果 = 进行中」的任务记录。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在列表中定位推送结果为「进行中」的任务，查看操作列 | 操作列不显示【重试】按钮；推送失败原因为空 |

#### 重试操作

##### 【P0】验证推送失败任务点击重试后状态变为进行中

> 前置条件
```
1) 使用具备【重试】按钮权限的账号登录系统。
2) 列表中存在一条「推送结果 = 失败」并带有失败原因的任务记录。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入【运维工具 → 同步任务列表】页面，等待列表加载完成后定位目标失败任务 | 目标任务的推送结果显示「失败」，操作列显示【重试】按钮 |
| 2 | 在目标任务行点击【重试】按钮，等待请求返回 | 推送结果立即变为「进行中」，【重试】按钮不再显示，无报错 |
| 3 | 等待后台推送完成后刷新列表 | 推送结果根据实际推送结果更新为「成功」或「失败」；推送完成时间更新为最新时间 |

##### 【P1】验证重试推送以最新底表数据为准

> 前置条件
```
1) 列表中存在一条历史推送失败的任务记录。
2) 该任务对应的运维工具-标准推送底表或数据目录-数据目录台账数据已被更新。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在目标失败任务行点击【重试】按钮，等待推送完成 | 推送任务以更新后的底表数据为准发起；任务的业务流水号保持不变 |
| 2 | 推送完成后查看 datablau 平台对应数据 | datablau 平台收到的数据属性与最新底表/台账一致，而非历史流程表单数据 |
