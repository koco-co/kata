## 数据货架管理 - 作品管理

### 列表页

#### 页面初始化与权限

##### 【P0】验证管理类账号进入作品管理页面后字段与按钮齐全

> 前置条件
```
1) 使用具备【数据货架管理 → 作品管理】操作权限的后台账号（超管 / 数据责任人 / 数据专员 / 数据管理员）登录系统。
2) 列表中已存在 BI 数据集与 BI 报表两类作品记录。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入【数据货架管理 → 作品管理】页面，等待列表加载完成 | 页面正常加载，列表展示作品记录；操作列显示【详情】【编目】【发布】【上架/下架】等按钮 |
| 2 | 在页面顶部查看页面级按钮 | 页面显示【立即同步】按钮 |

##### 【P1】验证只读账号进入作品管理页面时仅显示查看入口

> 前置条件
```
1) 使用仅具备页面查看权限的只读账号登录系统。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入【数据货架管理 → 作品管理】页面，等待列表加载完成 | 页面可正常访问；不显示【立即同步】【编目】【发布】【上架/下架】按钮，操作列仅显示【详情】 |

#### 状态流转

##### 【P0】验证已编目未发布的作品可发布并上架后再下架

> 前置条件
```
1) 使用具备发布与上下架权限的账号登录系统。
2) 列表中存在一条已完成编目、未发布、未上架的作品记录。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在目标作品行点击【发布】按钮并完成确认，等待列表刷新完成 | 作品的发布状态变为「已发布」；无阻断异常提示 |
| 2 | 在同一作品行点击【上架】按钮并完成确认，等待列表刷新完成 | 上架状态变为「已上架」，操作列显示【下架】按钮 |
| 3 | 点击【下架】按钮并完成确认，等待列表刷新完成 | 上架状态变回「未上架」；发布状态保持「已发布」 |

##### 【P1】验证未完成编目的作品无法直接上架

> 前置条件
```
1) 列表中存在一条编目状态为不完备的作品记录。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在目标作品行查看操作列 | 【上架】按钮置灰或不显示；hover 给出无法上架的提示 |

##### 【P1】验证立即同步操作可拉取最新作品并刷新列表

> 前置条件
```
1) 使用具备【立即同步】按钮权限的账号登录系统。
2) 上游 BI 平台存在新增或变更的作品。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在页面顶部点击【立即同步】按钮，等待请求返回 | 触发同步任务，按钮进入加载/不可重复点击状态 |
| 2 | 等待同步任务完成后刷新列表 | 列表新增或更新对应作品记录；同步完成时间字段更新为最新时间 |

#### 前后台联动

##### 【P0】验证后台上架后前台作品资源可见且下架后不可见

> 前置条件
```
1) 使用具备作品管理操作权限的后台账号登录系统。
2) 存在一条已编目、已发布但尚未上架的作品。
3) 存在可访问【数据货架 → 作品资源】页面的前台账号。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在后台对该作品执行【上架】操作 | 上架状态变为「已上架」 |
| 2 | 进入【数据货架 → 作品资源】页面并搜索该作品 | 前台可搜索到该资源并显示资源卡片 |
| 3 | 返回后台对该作品执行【下架】操作，再回到前台搜索 | 前台搜索结果中不再显示该资源 |

## 数据货架 - 作品资源

### 列表页

#### 目录与搜索

##### 【P0】验证默认进入作品资源页面时数据目录树与作品列表正确加载

> 前置条件
```
1) 使用具备【数据货架 → 作品资源】页面访问权限的前台账号登录系统。
2) 数据目录中存在 L0~L3 层级节点；不同节点下挂有作品资源。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入【数据货架 → 作品资源】页面，等待初始化完成 | 左侧数据目录默认展开 L1 级节点；L2、L3 节点折叠且可展开/收起 |
| 2 | 选中一个非末端目录节点 | 列表展示该节点及其所有下属子节点的作品资源 |

##### 【P1】验证中文名称模糊搜索与目录过滤取 AND 逻辑

> 前置条件
```
1) 数据目录中存在一个挂载多条作品的节点。
2) 该节点下至少存在 2 条名称包含相同关键字的作品。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 选中目标目录节点，在搜索框输入名称关键字后点击【搜索】，等待列表刷新完成 | 列表只展示同时满足「目录过滤」与「名称模糊匹配」的作品；结果数量与统计一致 |
| 2 | 切换到不包含该关键字作品的目录节点，等待列表刷新完成 | 列表显示空结果或 0 条命中提示 |

##### 【P1】验证高级搜索按多维条件组合查询作品

> 前置条件
```
1) 列表中存在可被高级搜索字段命中的 BI 数据集与 BI 报表作品。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在列表上方点击【高级搜索】，按 PRD 附录 7-#6 / #7 的字段填写多个查询条件并提交，等待列表刷新完成 | 列表只展示满足所有高级搜索条件且属于当前目录的作品 |
| 2 | 重置高级搜索条件，等待列表刷新完成 | 高级搜索条件清空，列表恢复到仅按目录过滤的结果 |

#### 收藏夹

##### 【P1】验证收藏夹支持分页与跨资源类型查看以及取消收藏

> 前置条件
```
1) 当前账号已收藏多条不同类型的资源（数据集 / 作品 / API / 时序设备）。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在页面右下点击星型图标 | 弹出「我的收藏夹」弹窗，默认按某资源类型展示，并显示分页 |
| 2 | 切换顶部资源类型标签 | 列表切换为对应资源类型的收藏内容 |
| 3 | 选择某条收藏点击【移除】，等待弹窗刷新完成 | 收藏从列表中移除；再次进入弹窗仍不在列表中 |
| 4 | 在分页 1 全选后切换到分页 2 再勾选 1 条 | 全选仅作用于当前页；跨页切换时已勾选状态被记忆 |

#### 资源卡片展示

##### 【P1】验证作品卡片默认按编目更新日期倒序排序且可切换正序

> 前置条件
```
1) 当前目录下存在至少 3 条编目更新日期不同的作品。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入页面后查看卡片排序 | 卡片默认按编目更新日期倒序排列 |
| 2 | 切换排序为正序 | 卡片按编目更新日期正序重新排列 |

##### 【P1】验证 BI 报表作品在编目无主图时卡片显示默认 icon

> 前置条件
```
1) 列表中存在一条 BI 报表类型（仪表盘 / 数据门户 / 自助取数 / 数据大屏 / 电子表格）的作品，未上传主图。
2) 列表中存在一条 BI 报表类型作品，已上传主图。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 在列表中查看上述两条作品卡片 | 未上传主图的作品卡片主图区显示默认 icon；已上传主图的作品卡片主图区显示该图，主图区域长宽固定且自适应拉伸不变形 |

##### 【P2】验证卡片显示来自中台的最新一次成功同步完成时间

> 前置条件
```
1) 列表中存在已成功同步过的作品。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 查看作品卡片上的「数据同步时间」字段 | 显示最近一次同步成功的完成时间，与后台同步记录一致 |

### BI 数据集详情

##### 【P0】验证进入 BI 数据集详情时查看次数 +1 并展示编目与详细信息

> 前置条件
```
1) 列表中存在一条 BI 数据集类型的作品。
2) 该作品已编目（含名称、数据目录、所属部门、Owner、描述）。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 记录该作品当前查看次数后点击进入详情页 | 详情页打开成功；该作品的查看次数 +1 |
| 2 | 查看「编目信息」区块 | 显示作品名称、数据目录、资产所属部门、资产 Owner、资源描述 |
| 3 | 查看「详细信息」区块 | 显示 BI 平台属性、字段信息（含维度信息表与度量信息表），表格支持展开/收起全部 |
| 4 | 点击【QuickBI 查看】按钮，等待新页面打开 | 跳转至 QuickBI 平台对应资源页 |

##### 【P1】验证拓展属性 TAB 仅在已启用拓展属性时显示

> 前置条件
```
1) 存在一条已启用业务属性的 BI 数据集作品。
2) 存在一条未启用任何业务属性的 BI 数据集作品。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 分别进入两条作品的详情页，查看是否存在「拓展属性」TAB | 启用拓展属性的作品显示「拓展属性」TAB 并展示业务属性 1-8；未启用的作品不显示该 TAB |

##### 【P1】验证数据预览 TAB 在有附件时显示并可下载

> 前置条件
```
1) 存在一条 BI 数据集作品已上传数据预览附件。
2) 存在一条 BI 数据集作品未上传数据预览附件。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入未上传附件作品的详情页 | 不显示「数据预览」TAB |
| 2 | 进入已上传附件作品的详情页，切换到「数据预览」TAB 并点击下载附件 | 显示数据预览附件卡片；下载成功获得后台编目发布的预览文件 |

### BI 报表详情

##### 【P0】验证 BI 报表详情展示编目与 BI 平台属性并支持 QuickBI 跳转

> 前置条件
```
1) 列表中存在一条 BI 报表类型作品（任一子类型，例如仪表盘）。
2) 该作品已编目并由 BI 平台同步完整属性。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 记录当前查看次数后点击进入详情页 | 详情页打开成功；查看次数 +1 |
| 2 | 查看「编目信息」与「详细信息-BI 平台属性」区块 | 编目信息显示作品名称、数据目录、所属部门、Owner、描述；BI 平台属性显示工作空间、唯一标识、目录路径、发布状态、修改人/时间、所有者、描述、编辑权限属性 |
| 3 | 点击【QuickBI 查看】按钮，等待新页面打开 | 跳转至 QuickBI 平台登录页或对应资源页 |

##### 【P1】验证不同 BI 报表子类型详情结构一致

> 前置条件
```
1) 列表中存在仪表盘、数据门户、自助取数、数据大屏、电子表格各一条作品。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 依次进入各子类型作品的详情页 | 各详情页的版块结构一致：编目信息、拓展属性（按需）、数据预览（按需）、详细信息-BI 平台属性、主图预览（按需）|

##### 【P1】验证 BI 报表主图预览仅在已上传主图时显示

> 前置条件
```
1) 存在一条 BI 报表作品已上传主图。
2) 存在一条 BI 报表作品未上传主图。
```

> 用例步骤

| 编号 | 步骤 | 预期 |
| ---- | ------------ | ------------ |
| 1 | 进入未上传主图作品的详情页 | 不显示「主图预览」栏目标题与内容 |
| 2 | 进入已上传主图作品的详情页 | 显示「主图预览」栏目；原图过宽时按页面宽度自适应缩放 |
