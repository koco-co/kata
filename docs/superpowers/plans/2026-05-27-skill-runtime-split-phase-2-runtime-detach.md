# Skill 运行目录拆分第二阶段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `.claude` 与 `.agents` 从 ai-core 投影状态切换为独立 runtime 入口：拆开 `CLAUDE.md` / `AGENTS.md`，删除 `CLAUDE.local.md`，移除 runtime 文件中的生成标记和现役 `.ai/core` 引用，并把这些纳入 `check:skills`。

**Tech Stack:** Bun >= 1.3、TypeScript、commander CLI、`bun test`、biome、现有 `engine/tests/cli-runner.ts`。

```typescript
import { existsSync, lstatSync, readdirSync, readFileSync } from "node:fs";
import { join } from "node:path";

export type RuntimeDetachRule =
  | "RUNTIME_ENTRY_MISSING"
  | "RUNTIME_ENTRY_SYMLINK"
  | "RUNTIME_LOCAL_ENTRY_PRESENT"
  | "RUNTIME_SYNC_RULE_MISSING"
  | "RUNTIME_GENERATED_MARKER"
  | "RUNTIME_AI_CORE_REFERENCE";

export interface RuntimeDetachViolation {
  rule: RuntimeDetachRule;
  path: string;
  message: string;
}

export interface RuntimeDetachReport {
  passed: boolean;
  violations: RuntimeDetachViolation[];
}

const ENTRY_FILES = ["AGENTS.md", "CLAUDE.md"] as const;
// Uses `includes()` substring matching — flexible enough to survive
// minor formatting differences (backtick vs plain, trailing punctuation).
const ENTRY_REQUIRED_PHRASES = [
  "Claude 与 Codex 同等优先",
  "同步评估另一套",
  "不得把",
  "作为当前规范来源",
] as const;
const GENERATED_MARKERS = ["generated by kata ai-core", "ai-core-hash"] as const;
const ACTIVE_AI_CORE_REFERENCES = [".ai/core", "projection render", "projection lock"] as const;

export function checkRuntimeDetach(root: string): RuntimeDetachReport {
  const violations: RuntimeDetachViolation[] = [];
  checkEntryFiles(root, violations);
  checkNoLocalEntry(root, violations);
  for (const file of collectRuntimeTextFiles(root)) {
    checkFileContent(file, violations);
  }
  return { passed: violations.length === 0, violations };
}

function checkEntryFiles(root: string, violations: RuntimeDetachViolation[]): void {
  for (const entry of ENTRY_FILES) {
    const path = join(root, entry);
    if (!existsSync(path)) {
      violations.push({
        rule: "RUNTIME_ENTRY_MISSING",
        path,
        message: `${entry} is missing.`,
      });
      continue;
    }
    if (lstatSync(path).isSymbolicLink()) {
      violations.push({
        rule: "RUNTIME_ENTRY_SYMLINK",
        path,
        message: `${entry} must be a regular runtime-specific file, not a symlink.`,
      });
      continue;
    }
    const text = readFileSync(path, "utf8");
    for (const phrase of ENTRY_REQUIRED_PHRASES) {
      if (!text.includes(phrase)) {
        violations.push({
          rule: "RUNTIME_SYNC_RULE_MISSING",
          path,
          message: `${entry} must include synchronization rule phrase '${phrase}'.`,
        });
      }
    }
  }
}

function checkNoLocalEntry(root: string, violations: RuntimeDetachViolation[]): void {
  const path = join(root, "CLAUDE.local.md");
  if (existsSync(path)) {
    violations.push({
      rule: "RUNTIME_LOCAL_ENTRY_PRESENT",
      path,
      message: "CLAUDE.local.md must be removed; local settings belong in user/local config.",
    });
  }
}

function collectRuntimeTextFiles(root: string): string[] {
  const files: string[] = [];
  for (const rel of ["AGENTS.md", "CLAUDE.md", ".claude/INDEX.md", ".agents/INDEX.md"]) {
    const path = join(root, rel);
    if (existsSync(path) && !lstatSync(path).isSymbolicLink()) files.push(path);
  }
  for (const runtimeDir of [".claude", ".agents"] as const) {
    const skillsRoot = join(root, runtimeDir, "skills");
    if (!existsSync(skillsRoot)) continue;
    for (const entry of readdirSync(skillsRoot, { withFileTypes: true })) {
      if (!entry.isDirectory()) continue;
      const skillMd = join(skillsRoot, entry.name, "SKILL.md");
      if (existsSync(skillMd)) files.push(skillMd);
    }
  }
  return files;
}

function checkFileContent(path: string, violations: RuntimeDetachViolation[]): void {
  const text = readFileSync(path, "utf8");
  for (const marker of GENERATED_MARKERS) {
    if (text.includes(marker)) {
      violations.push({
        rule: "RUNTIME_GENERATED_MARKER",
        path,
        message: `${path} still contains generated marker '${marker}'.`,
      });
    }
  }
  for (const ref of ACTIVE_AI_CORE_REFERENCES) {
    if (text.includes(ref)) {
      violations.push({
        rule: "RUNTIME_AI_CORE_REFERENCE",
        path,
        message: `${path} still references '${ref}' as runtime content.`,
      });
    }
  }
}

export function formatRuntimeDetachReport(report: RuntimeDetachReport, root: string): string {
  if (report.passed) return "runtime detach passed";
  const lines = report.violations.map((violation) => {
    const rel = violation.path.startsWith(root)
      ? violation.path.slice(root.length + 1)
      : violation.path;
    return `${violation.rule}: ${rel}: ${violation.message}`;
  });
  return ["runtime detach failed", ...lines].join("\n");
}
```

- 不要求两边文件逐字一致，但用户入口语义、交付产物清单、验证口径和证据底线必须一致。

## Claude Code Runtime 规则

- Claude Code skill 的稳定触发信息来自 `.claude/skills/<name>/SKILL.md` frontmatter 的 `name` 与 `description`。
- slash-command 专属 frontmatter 只能在后续 `.claude/commands/**` 设计中单独使用，不写进 `SKILL.md` 白名单。
- `/skill` 名继续可用；显式 `/case-draft`、`/case-edit` 等命令按下方路由表处理。
- 本项目不再使用 `CLAUDE.local.md` 作为入口；本地设置放用户级配置或 `.claude/settings.local.json`。

## 路由规则

- 使用下方命令索引作为公开 slash-command 路由表。
- 仅输入 Lanhu/Axure URL → 静默转发到 `case-draft`，由 case-draft 产生首个用户可见结果。
- 仅输入 ZenTao bug URL/bug-view URL/bug ID → 转发到 `case-hotfix`；若记录未修复或缺少修复范围，由该 skill 生成待办项而非回退到 `bug-file`。
- 用户提供 XMind/CSV/Archive MD 用例产物路径或要求编辑/同步/标准化已有用例 → 转发到 `case-edit`。
- 用户要求记录、查询、维护项目业务知识/规则/术语，或询问 "XX 是什么"（涉及项目特定业务概念）→ 静默触发 `knowledge-curate`。
- `/playwright-automation` 缺少环境参数时，按 skill 内置环境确认协议处理后再开始发现、预检或浏览器操作。

### 多技能匹配优先级

- 精确格式/URL/路径匹配 > 意图关键词匹配 > 通用请求。
- 各 skill 的 `must_not_trigger_when` 优先级高于 `must_trigger_when`；must_not_trigger_when 明确排除的场景不路由到该 skill。
- 同一输入命中多个 skill 且无法判定时，按上述顺序选择优先 skill；仍不确定时向用户确认意图。

### 无匹配回退

- 无 skill 匹配的请求由 AI 自行处理，不强制套用 skill 路由。
- 共同同步契约见 `docs/skills/contracts/runtime-skill-sync.md`。
